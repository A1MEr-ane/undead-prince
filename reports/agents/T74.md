### 默认与新基线的边界

任务同时要求“T68 修正会改变结果，旧数据作废”和“默认关时与 T73 逐字一致”。因此保留默认 schema 2 作为兼容基线；`analysis.enabled=true` 或 `phase_b.enabled=true` 才使用 schema 3 新口径。旧 T68 数据不能与 schema 3 混合比较，应重跑 DSH 矩阵。没有删除或改写禁改范围内的历史报告。

新分析中 `analysis.route_values` 独立于 `targeting.values.archer`；机器人可分别指定 `route_by_strategy` 与 `archer_focus_by_strategy`。弓兵偏好接入实际最近敌人评分与切换滞后，机制测试用“近盾兵、稍远弓兵”证明偏好开关改变实际索敌，同时改变弓兵价值不改变选路。

拥堵只统计有移动意图、尚未到位且连续 3 秒净位移不足 0.15 格的单位。站岗、近战、攻击结构、眩晕、转移、撤退都排除；持续缓慢前进不算。各阶段为初夜 `[0,120)`、中夜 `[120,240)`、黎明前 `[240,300]`，另记撤退。存活峰值包含转移中的活兵，各指标独立取峰。

### 感知和地形权限

刺客出生隐藏；有效守军距离不超过 1.4 格且二维陆地/墙体通视时发现，或主动出手/受到正伤害时暴露；发现永久保持。每个固定步在调度前检查。隐藏单位不进入守军索敌和调度威胁，全图感知开关也不穿透潜行。该原型不实现视锥、听觉或基于画面的遮挡。

指定崖壁 `[12,37] -> [12,21]` 为刺客独占的 4 秒特殊连接，转移期间不能交战或占领。普通兵仍须走普通通路；自然地形无血量。新增墙三段为 west 60 HP、east 75 HP、highland 50 HP，其他普通墙没有攻击接口。山洞 `all / undead / assassin` 实际约束双方通行，容量与耗时沿用原参数。

## 风险与已知不足

- 新兵种和三组机器人是可玩工具与诊断样本，数值未平衡；三个种子不能证明准备攻势提升胜率，也不能替代用户手玩。新分析基线 feint 的移动拥堵仍为 0.9805 次/出生单位，超过旧参考 0.5；未将玩法指标包装为已通过。
- 攀崖是带耗时的显式连接，转移期间隐藏模型；未制作攀爬动画或真正地形网格。刺客/巨人的近战使用简化冷却攻击，不复用剑盾的招架/拼刀套路。
- 原 `siege.tscn` 是本次阶段 B 手玩入口。T70 底部战区按钮与新增卡片位置重叠，未完成 T70 阶段 B UI 适配；默认关闭时 T70 回放保持兼容。
- 山洞权限为 all 时守军实际可走洞，但调度 ETA 和 `map_scale.defender_routes` 仍沿用原地面估计，可能高于走洞实测；不能把该估计当精确到达承诺。
- `run_matrix.py` 的旧版摘要仍使用旧拥堵列名与解释；schema 3 应读取 `metrics_version` 和原始 JSON，后续 DSH 汇总须采用新口径。
- 默认完整 SIEGE 哈希回归针对开工时 Godot 4.7.2、默认参数和固定种子；不承诺跨引擎版本或平台逐位一致。
