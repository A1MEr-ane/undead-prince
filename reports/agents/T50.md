### JSON 结构

每个旧部文件顶部是该旧部的状态定义：

```json
{
  "crew": "bernard",
  "crew_name_zh": "伯纳德",
  "status": {
    "status_id": "broken_formation",
    "name_zh": "破阵",
    "effect_zh": "敌人盾牌失效，格挡判定取消，持续 4 秒。",
    "params": {"duration": 4}
  },
  "boons": []
}
```

`duo.json` 不是单一旧部，顶层 `status` 为 `null`；双人增益的 `status` 字段引用两位旧部已定义的状态。

每条增益含任务卡要求的 `id / crew / slot / name_zh / effect_zh / status / requires / params`。另保留三个原文辅助字段，避免映射时丢信息：

- `requires_zh`：`docs/boons.md` “依赖”列的原文；专精、渡魂人、双人没有该列时为 `null`。
- `cost_zh`：渡魂人“代价”列原文。
- `source_zh`：双人增益“剧情来源”列原文。

`status` 只在该条效果明确写“附带/获得/被点燃/带……光环”时填写；不确定的（如“引燃”“火径”属于燃烧系统但不是明确施加“冥燃”状态）写 `null`，避免替设计做判断。
