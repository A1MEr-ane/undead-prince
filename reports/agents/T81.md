## 修改后对照

| 目标 | 改动及结果 |
|---|---|
| 1.1 站立超时 | 接战范围内主动靠近，命中仍需进入武器攻击范围。远离已接战单位时沿行军方向推进。B01 首次接战为 0.77 秒，另测初距 1.2 米，两秒内有招架、拼刀。 |
| 1.2 减少折返 | 索敌、主动改道、局部绕障和新支援任务共用十秒滚动窗口，最多两次变更。目标死亡立即解锁。普通单位保留当前行军点和敌人切换滞后。 |
| 1.3 地形阻挡 | 线段逐格检测，两格之间的斜角也检查两侧。B03 和擦过封闭格角的补测通过。 |
| 1.4 拥堵 | 仅记录有移动意图却没有推进的单位。同一路口排队满五秒可改走可达入口，同目的地的队伍按剩余距离和固定 ID 礼让。山洞按到达顺序限流，出口被占时寻找空位。补充窄门场景记录 3 人改道，解除障碍后原路线有 7 人继续通过。T80 B02 原场景 10 人全数通过，行军拥堵为 0，仍因要求改道而失败。 |
| 1.5 接战距离和受击 | 起手与命中都校验范围和无遮挡。拼刀用无符号进度差。正面主动招架归零，无招架的正面剑击照常伤害。加上受击冲击累积、倒地和起身。B12 和正负差值补测通过。 |
| 1.6 偏好与走向 | 部署选最近可达入口，可以显式传路线提示。索敌独立应用兵种偏好，同分按固定 ID 排序。 |
| 2 普通亡魂 | 按路线和入口行军，路上接敌，战后恢复推进。行军点不再随近敌移动。 |
| 2 暗影刺客 | 合法部署优先走能缩短路程的崖壁。锁定最近可达后排，死亡后找下一名。B05 在 5.73 秒击杀弓兵，之前未伤到盾兵。 |
| 2 缝合巨人 | 按行军距离选可达墙段或门，贴近持续攻墙，满足既有敌人数量阈值时横扫，破口后沿开放路径推进。B04 在 9.03 秒破墙并通过。 |
| 2 集结和恢复 | 集结立即覆盖自主行军，抵达后恢复原路线。支持原有动态作用范围和时限。B09 三名亡魂均在首个模拟步（0.033 秒）响应并恢复自主。 |
| 3.1 驻防 | 锚点独立于当前敌人。守军在追击半径内近战，战后归位。 |
| 3.2 支援 | 威胁决定需求量，扣除已指派兵力。保留出发地最低驻防及出发、到达后的任务锁。B06 的 2 名与 8 名亡魂分别引出 1 人和 3 人。B07 未反复改派。 |
| 3.3 弓兵 | 保留驻地，有射击条件时继续射击，敌人近身切近战。高地弓兵保持高处火力，敌人贴身时可以还击。B08 在 0.23 秒响应。 |
| 3.4 盾兵 | 初始蛇形编队尾行居中，用驻地锚点和追击半径守住阵线。 |
| 3.5 骑兵 | 优先派机动预备队，骑兵索敌对行军单位加权，通行复用排队与局部绕障。 |
| 3.6 撤退 | 保持撤退城门开放，取消调动及交战，按到港口的最短流场行军，受威胁时在等距出口间避敌。B10 通过。关闭测试夹具的伤害后，西侧守军前 12 秒剩余路径 66→46 格，随后登船。 |
