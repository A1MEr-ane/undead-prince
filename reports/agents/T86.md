## 结果：完成

单局入口、模拟与行为场景沿用本分支已有实现。续做补齐了实际资产接口、显示层回归检查和固定验收脚本。

从仓库根目录运行：

```sh
godot --path . --rendering-method gl_compatibility attempts/single_battle/main.tscn
tools/verify/single_battle.sh
tools/verify/single_battle.sh --scenario=B05 --watch --zone=highland
```

按 `1`–`4` 选择兵种，在青色登陆区长按左键部署。按 `F` 集结，按 `G` 选择法术，再点当前战区地面。默认狂化，把覆盖 JSON 设为 `{"spell":{"active":"weakness"}}` 并通过 `-- --params=路径` 运行即可测试虚弱。两种配置的默认上限均为每局两次。`Tab` 或地图按钮展开地图。点击地图或战区标签跳转机位，右键取消指令，`R` 再战。

## 改动

- `siege.gd`、`siege_unit.gd`、`siege_phase_b.gd`、`siege_params.json` 组成固定步战斗。四种亡灵实现骨堆重组、潜行背刺和攀崖、破墙与扇形横扫、冥火弹范围眩晕。守军沿用盾兵格挡、弓兵高地射击和近战应对、骑兵支援、冲锋与通路限制。
- `siege_view.gd` 和 `camera/` 提供功能版 HUD、固定机位、战况、实地增援方向和离屏提醒。地图点击由 UI 消费。五分钟倒计时驱动光照，胜利后可观看守军撤离或跳过。
- `battle_assets.gd` 读取 T85 的 `terrain/grey_tide.json`（`schema_version: 1`），使用其中的 `map`、`cameras`、`deploy_points`、`phase_b` 和 `surfaces`。`siege_map.gd` 以多边形坡面计算高度和鼠标落点。`painted_field.gd` 加载 `grey_tide.tscn`，同步 `set_time`、`set_structure_state`、`set_boat_progress`。缺少 T85 资产或传入 `--graybox` 时使用默认灰盒地图与样张材质。
- `battle_sprites.gd` 读取 `assets/sprites/units/<id>/<id>_ink.png` 与 `<id>_uv.json`（`swordsman_uv_v1`）。七个目录 ID 为 `skeleton`、`shadow_assassin`、`stitched_giant`、`lich`、`shieldman`、`archer`、`cavalry`。按帧矩形、动作时长、循环标志及站姿脚底锚点播放。缺少对应资产的兵种使用样张侧影。
- `tools/verify/single_battle.sh` 严格运行 B01–B12、U01–U04 和 C01，验证真实显示节点，再对正式入口执行两次相同种子回放并比较完整结果行。工作树包含 Godot 为本任务脚本生成的 `.gd.uid`。
