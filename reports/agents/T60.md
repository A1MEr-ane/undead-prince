## 实现细节

### 输出结构

```text
reports/sim/20261125-211513/
  meta.json          # 配置、种子范围、并行数、quit_at、Godot 版本、git 基线、队伍表
  runs.jsonl         # 50 条 main + 3 条 recheck，每行一个 JSON 对象
  records/           # 每局一份记录（便于中断后排查）
  logs/              # 每局 Godot 原始输出
  summary.json       # 机器读
  summary.md         # 人读
```

`runs.jsonl` 单行关键字段：

```json
{"index":0,"kind":"main","pair_index":null,"seed":1,"battle_id":"proto",
 "exit_code":0,"duration_s":19.67,"timed_out":false,
 "result":{"banner":"王旗已夺取","time":16.22,"alive":{...},"stats":{...}},
 "result_raw":"{\"alive\":...}","hitch_count":0,"script_errors":[],
 "alive_by_faction":{"player":7,"defender":4,"unknown":0},"log":"reports/sim/.../logs/main_000_seed1.log"}
```

### 配置切换

`batch.sh` 把 `--config <路径>` 换算成 `main.gd` 已有的 `--battle=<相对 data/battles 的路径>`：

- `--config data/battles/sweep_01.json` → `--battle=sweep_01`（T49 参数扫描用这个）。
- `--config tools/sim/fixtures/alt_proto.json` → `--battle=../../tools/sim/fixtures/alt_proto`（已实测可加载）。
- 配置必须在项目目录内且为 `.json`；不需要改 `main.gd`，也不在 `data/` 里写任何东西。
- 配置 JSON 会在开跑前校验 `squads` 非空。

### 统计口径

- 胜率：`wins / completed`；同时给出 `wins / (wins+losses)`，未分胜负不计入后者。
- 用时：所有完成局 + 已分胜负局两个分布。
- STATS：同一批配置每局都应有这些键；某局缺某个键时按 0 计，再对全部完成局取平均（避免只对出现过的局取平均而高估）。
- 剩余人数：某局 `alive` 缺某队时按 0 计；玩家/守军用 meta 里的 `is_player` 分组。

## 风险与已知不足

1. **坐标异常检查在真实数据上不可用**：`RESULT` 没有坐标字段。工具的 `extract_positions` 已支持 `positions`/`units`/`squads` 三种载体和 `map_size`，只要 `main.gd` 补字段即可启用；自测用假数据覆盖了 NaN/越界。
2. **HITCH 对负载敏感**：4 并行跑 50 局没有 HITCH。要测性能或严格 HITCH 基线时用 `--jobs 1`，避免并行争抢造成假阳性。
3. **60 秒无接战规则**：只在观察窗口达到 60 秒时判定；如果战斗在 60 秒前结束且全程零接战，当前不会报 `no_engagement`。这是按“60 秒内没有接战”的字面口径，若 Lead 想连短局也报，改 `summarize.py` 顶部常量/条件即可。
4. **无头退出没有单独 STATS 行**：`main.gd` 的 `STATS` 只在截图路径打印。汇总使用 `RESULT.stats`，数据完整；如果以后有脚本依赖 `STATS` 行，需要在 `_print_result_and_quit` 补一行（allowed 之外，handoff）。
5. **复跑抽样不针对异常局**：固定首/中/末，本次唯一负局 seed 21 未被抽到。需要时可单独跑 determinism.sh。
6. **`--config` 路径换算依赖 Godot 的 `..` 解析**：`tools/sim/fixtures/alt_proto.json` 已实测；T49 在 `data/battles/` 下的配置走最简单的 `--battle=<id>`，没有这个依赖。
7. **提交被沙箱阻断**：`git add`/`git commit` 报 `Unable to create .../index.lock: Operation not permitted`；`danger-full-access` 重试无审批通道。工作区改动完整保留，`reports/sim/` 是未入库的验证产物。
