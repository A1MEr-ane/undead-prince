## 给 T86 的接口说明

**读取**

- 使用原有 `<id>_ink.png` 和同目录 `<id>_uv.json`。文件夹与 id 分别是 `skeleton`、`shadow_assassin`。格式仍为 `swordsman_uv_v1`，8 列、17 行、单格 128×128、整图 1024×2176。默认脚底锚点 `[64,124]`，朝右。按清单读 `rect`、脚底锚点、`duration` 和 `loop`。用 `idle` 的站姿像素高度换算 `pixel_size`，按原规则翻转。可选字段 `presentation` 给出相对普通兵的站高比例与预览比例。
- `frames`、`start_frame` 和 `event_frames` 都以整张图集为基准，事件时间 `events` 以动作内秒数为基准。攻击 `hit` 在第 4 格（4/12 秒），刺客背刺在第 3 格（0.25 秒）。`hit`、`death` 兼容旧调用。新增受击和死亡分类由 T86 按伤害来源选片，击退位移、击飞抛物线、头顶眩晕星点交给单局逻辑。
- 斩杀尾格可直接接骷髅的 `bone_pile`。刺杀和压碎先保留各自尾格，再按复活状态切到同一 `bone_pile`。使用 `reassemble` 从骨堆聚回站姿。

**镜头**

- T86 用镜头对齐的 billboard，竖直正交尺寸可按 `S = 视口画高 × 步兵世界站高 / 72` 换算。以 1080p、T86 当前骷髅站高 1.5 为基准，海岸机位从 `size=26` 调到 `22.5`，视口竖向覆盖缩小约 13.5%，像素放大约 15.6%。16、18、17 的其他机位已经分别约 101、90、95 px，当前无需再拉近。调整后要复核海岸部署区和 UI 遮挡。
- T84 的 `size=18.6`、骷髅站高 1.23 在 1080p 已约 71 px。预览的巨人与骑乘分别按 1.7 倍和默认 1.65 倍出图。以上是按现有相机参数计算的读图尺寸。

**步点与跳步**

- `walk` 与 `sneak` 均为 4 帧循环，总长 4/12 秒。第 0 格 `right_step` 在 0 秒，第 2 格 `left_step` 在 2/12 秒。两次步点双脚都贴地，事件所指脚在前。第 1、3 格给脚的转换，上身和武器锁定。
- 按原型 `Unit._stepping_update` 用 60 Hz 更新演出步相。在每次换步切换 `parity`，0 对应右脚、1 对应左脚。每半周期只触发一次落脚事件。把归一化步相 `p` 映到 `anim_t = (parity + p) * 2/12`。跳步快慢跟随原型 `step_time = (d * .08 + .4) / lerpf(max_speed, 2., .8)`，其中 `d` 为这一步的水平距离。处理开始、停止和低位移阈值时沿用原型逻辑。
- 在显示根上做阶跃插值和跳步。原型竖向形变为 `stretch = .01 * sin(PI * p)`，可沿用约 1% 的幅度；落脚处回到 0。平地可用 T86 已有的 `combat.hop_height=.09` 乘 `sin(PI * p)`，上台阶由原型的高度插值处理。导航位置和碰撞仍由模拟驱动。巨人步点可触发扬尘，巫妖漂浮走独立轨道。
