## 给 T86 的接口说明

### 图集与动作

- 普通兵资产 id 由 `skeleton` 改为 `zombie`。模拟侧可保留 `ghost`，把 `BattleSprites.FOLDERS["ghost"]` 映射到 `zombie`，读取 `res://assets/sprites/units/zombie/zombie_ink.png` 和同目录的 `zombie_uv.json`。原骷髅配方和资产收在 `assets/archive/skeleton/`。
- 格式沿用 `swordsman_uv_v1`。每格 128×128，8 列，脚底锚点 `[64,124]`，默认朝右。丧尸整图 1024×2304（18 行），刺客整图 1024×2176（17 行）。按清单读取 `rect`、行数、锚点、`duration`、`loop` 和待机像素高度。修订 4 的刺客继续使用同一资源路径与读取方式。
- 复活等待时以循环 `downed` 替换 `bone_pile`（12 帧，1 秒）。复活动作用 `rise_again` 替换 `reassemble`（8 帧，8/12 秒，`standing` 事件在末格 7）。同步处理 `siege_view.gd` 的倒伏分支和 `pose_for()`、`siege_unit.gd` 的复活动作选择及结束条件、`tests/presentation.gd` 的动画断言。眩晕倒地和起身仍用 `fall`、`sit`、`rise`。
- 通用攻击 `hit` 在局部第 4 格（4/12 秒），刺客背刺在第 3 格（0.25 秒）。`event_frames` 和 `start_frame` 使用图集全局帧号，`events` 使用动作内秒数。按伤害来源选受击与死亡分类。丧尸先播放死亡尾姿，再按复活条件进入 `downed`。击退和击飞位移、眩晕星点、压碎碎屑由单局演出负责。

### 镜头

- 镜头对齐的 `Sprite3D` 在 1080p 下用 `正交 size = 1080 × 步兵世界站高 / 72`。按当前步兵站高 1.5，海岸机位可从 26 拉近至 22.5，竖向覆盖缩小约 13.5%，步兵从约 62 px 增至 72 px。另三个机位的 size 16、18、17 分别约为 101、90、95 px。海岸镜头调整后需复核部署区和 UI 遮挡。
- 预览固定为每模型单位 37.5 px，巨人和骑乘按约 1.7 倍和默认 1.65 倍显示。场景里的世界高度配置需体现兵种体量。

### 步点与跳步

- `walk` 和刺客 `sneak` 均以 12 fps 循环 4 帧。局部第 0 格为 `right_step`（0 秒），第 2 格为 `left_step`（2/12 秒）。步点两脚贴地，命名脚在前。第 1、3 格转换脚位，上身和武器锁定。
- 以 60 Hz 推进原型 `Unit._stepping_update` 的步相，0 为右脚，1 为左脚。切换步相时落脚一次。用 `anim_t = (parity + p) * 2/12` 把半周期进度 `p` 映射到图集。步时沿用 `step_time = (d * .08 + .4) / lerpf(max_speed, 2.0, .8)`，`d` 为步长，起停距离阈值为 0.01。
- 显示根按原型在两步间插值，纵向缩放量用 `.01 * sin(PI * p)`，落脚归零。平地轻跳用 `hop_height=.09` 乘 `sin(PI * p)`，台阶沿用原型高度插值。`refresh_units()` 当前只对占位图做跳步，正式图集分支也应接同一步相。巨人可在落脚时加扬尘，巫妖用独立漂浮轨道。
