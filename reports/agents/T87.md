## 给 T86 的接口说明

**图集与动作**

- 普通兵资产 id 从 `skeleton` 改为 `zombie`。T86 可保留模拟侧的 `ghost` 键，将 `BattleSprites.FOLDERS["ghost"]` 映射为 `zombie`，路径为 `res://assets/sprites/units/zombie/zombie_ink.png` 与同目录 `zombie_uv.json`。
- 格式为 `swordsman_uv_v1`。两个图集单格均为 128×128、8 列、脚底锚点 `[64,124]`、默认朝右。丧尸 18 行、整图 1024×2304，刺客 17 行、整图 1024×2176。沿用清单的 `rect`、锚点、`duration`、`loop` 与待机像素高度。图集行数按清单读取。
- 将复活等待时的 `bone_pile` 调用改为循环 `downed`（12 帧，1 秒），把复活动作 `reassemble` 改为 `rise_again`（8 帧，约 0.667 秒，`standing` 在末格 7，事件时间 8/12 秒）。同步检查 `siege_view.gd` 的倒伏分支、`pose_for()` 和 `siege_unit.gd` 的复活动作选择与完成条件。更新 `tests/presentation.gd` 的骨堆断言，改验丧尸倒伏与爬起。既有眩晕倒地仍用 `fall`、`sit`、`rise`。
- 攻击 `hit` 事件为局部格 4（4/12 秒），刺客背刺为格 3（0.25 秒）。`event_frames` 和 `start_frame` 是图集全局帧号，`events` 是动作内秒数。按伤害来源选受击与三种死亡，先保留死亡尾姿，再按复活条件进入 `downed`。击退、击飞抛物线、眩晕星点和压碎时的冷灰与冥火碎屑由单局演出处理。

**镜头**

- 镜头对齐的 `Sprite3D` 在 1080p 下用公式 `正交 size = 1080 × 步兵世界站高 / 72`。使用 T86 当前的普通兵站高 1.5，海岸机位从 26 拉近到 22.5，竖向覆盖缩小约 13.5%，人物像素高从约 62 到 72。其他三个机位的 size 为 16、18、17，普通兵约为 101、90、95 px。海岸调整后需复核部署区和 UI 遮挡。
- 预览固定为每模型单位 37.5 px，大型与骑乘按约 1.7 倍和默认 1.65 倍显示。场景高度配置需体现目标兵种体量。

**步点与跳步**

- `walk` 和 `sneak` 都是 4 帧循环。局部第 0 格 `right_step` 为 0 秒，局部第 2 格 `left_step` 为 2/12 秒。两个步点的双脚同时贴地，命名脚在前。第 1、3 格用于转换脚位，躯干、头和武器锁定。
- 在显示侧以 60 Hz 推进原型 `Unit._stepping_update` 的步相。以 0 表示右脚、1 表示左脚。切换步相时触发一次落脚，把半周期进度 `p` 映到 `anim_t = (parity + p) * 2/12`。步时沿用 `step_time = (d * .08 + .4) / lerpf(max_speed, 2.0, .8)`，其中 `d` 是该步水平距离。起停沿用原型的 0.01 距离阈值。
- 显示根按原型的步间插值推进，`stretch = .01 * sin(PI * p)`，落脚时回零。平地轻跳可用 T86 已有的 `hop_height=.09` 乘 `sin(PI * p)`，台阶高度沿用原型插值。现有 `refresh_units()` 把跳步只用于占位图，正式图集分支也需接该步相。巨人可在落脚加扬尘，巫妖用独立漂浮轨道。
