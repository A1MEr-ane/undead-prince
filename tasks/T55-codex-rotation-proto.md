## 目标
验证 `docs/research/FLEET_ART_TECH_DECISION.md` 第 1–3 节的结论：朝向镜头的 2D 精灵，能否同时做到 360° 丝滑旋转、飞行物、魔法特效。
**只在 `proto/rotation/` 里做独立原型，不改生产代码。** 可以复制生产代码（`scripts/unit.gd`、`shaders/unit.gdshader`、现有精灵图集）到原型目录里修改；用的都是原创素材。

## 要做
1. **镜头**：正交，俯角 30°，**连续方位角**。
   - 右键或中键拖动自由旋转；Q/E 转 45°；滚轮缩放。
   - 阻尼与帧率无关；角度不归一化，跨 0° 不绕远路。
   - 无头模式参数 `--orbit=秒数`，用来自动连续绕两圈再反向转。
2. **小兵**：
   - 复用现有精灵和着色器，加墨线外轮廓和阵营边光（亡魂青绿、王国暖金）。
   - 左右翻转改成约 0.08 秒的横向压扁过渡；快速旋转时滞回加大。
   - 再做一个对照组：盾牌是独立的 3D 网格，挂在身体上。
3. **飞行物**：
   - 弓箭齐射：抛物线 + 轴向公告板箭身 + 条带拖尾，命中后插在地上留 3 秒。
   - 冥火弹：发光球 + 拖尾 + 命中后爆发。
4. **魔法**，每类至少一个：
   - 地面范围：贴花圈和燃烧地面
   - 体积爆发：手绘风格的公告板序列图，可以用程序生成的占位图
   - 方向性：扇形喷火，世界空间扇形平面加粒子
   - 光束 / 闪电链：轴向公告板
   - 屏幕空间：命中停顿和震屏
5. **压力测试**：`--units=50|200|500`。打印平均、p95、p99 帧时间和绘制调用数，分别测"只渲染"和"带简单移动逻辑"两种情况。
6. **截图**：`--shots`。在 8 个方位角（0、45、…、315 度）各截一张包含全部特效的静帧；再从连续旋转中每 0.1 秒截一帧，取 20 帧。存到 `shots/t49/`。
7. `tools/verify/proto_rotation.sh`：无头跑 `--orbit` 和 `--units=200`。检查不报错、打印出帧时间、截图文件齐全（截图需要窗口；无头环境截不了就跳过截图检查，但要写明）。

## 验收
- [ ] 脚本通过
- [ ] 报告里有 50/200/500 个单位的帧时间表，注明机器、分辨率、渲染后端
