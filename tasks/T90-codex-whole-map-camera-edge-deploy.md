## 背景
用户第一次试玩单局后决定（`docs/alignment-2026-11-28.md` 第 7 节）：
- 局内改成**整张地图的整体视角，可以局部放大**，参考部落冲突。不再用单战区固定视角，也不再用地图界面切换战区。
- 部署改成**沿边线部署**，不再用一块部署区。
- UI 先保持功能版，以后再做。小兵马上会换成 3D 模型（另一个任务），本任务不改小兵的画法。

## 要做
1. **镜头**：
   - 固定俯角，不旋转。默认视野框下整张战场。
   - 滚轮和触控板双指可以缩放：最远看全图，最近时普通兵在 1080p 下约 90 像素高。缩放以鼠标位置为中心。
   - 拖动平移，限制在地图范围内。缩放和平移都要有平滑的缓动，不能跳。
   - 删掉战区切换和 Tab 战术地图。原来战区标签显示的信息（战况、增援动向）改成地图上的世界空间标记，跟着缩放显示。
2. **边线部署**：
   - 每张图定义一条**部署边线**（折线），画在守军阵地外圈。玩家只能在边线外侧的可走地面上部署，比如海岸、码头、空地。
   - 选中兵种卡时，边线高亮成虚线；鼠标在可部署处显示落点，在不可部署处显示红色提示。
   - 长按连放沿用原来的节奏。按住拖动时，沿拖过的位置依次放兵。
   - 参数文件里保留"占领后边线外扩"的开关，默认关。
   - 边线数据写进地形数据（`attempts/single_battle/terrain/grey_tide.json` 可以改）。机器人策略改成沿边线选点。
3. **测试**：
   - B01–B12、U01–U04、C01 改用边线部署后要继续通过。
   - 新增两项：
     - 边线内部署被拒绝。
     - 缩放和平移不影响模拟的确定性：同一个种子，不同的镜头操作，结果一致。
4. **截图**：在 `shots/t90/` 出三张：全图默认视野、中等缩放、最近缩放。截不了就写明，Lead 会补拍。
