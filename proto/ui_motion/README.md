# T56 · UI 动效校准原型

独立 Godot 4.7 项目，固定设计尺寸 1280 × 800。全部人物、增益、航路和场景均为几何占位；台词只用于测时，不作为剧情设定。没有引用生产脚本、场景或美术。

## 运行

从仓库根目录执行：

```sh
godot --path proto/ui_motion
```

也可以用 Godot 编辑器打开这里的 `project.godot`。字体随目录携带，运行无需下载或安装系统字体；脚本直接读取字体字节，第一次命令行启动也不依赖编辑器导入。

## 操作

| 按键 | 功能 |
| --- | --- |
| 1 | 增益选择：立绘 → 台词 → 三卡；鼠标悬停、点击确认 |
| 2 | 三轮对话自动演示；明暗交接与两张表情交叉淡化 |
| 3 | 金线和船标沿航线前进，然后涨潮与退潮 |
| 4 | 战场减速、去饱和、暗角 → 钟波 → 全黑 → 提灯、台词 → 据点 |
| 5 / 6 / 7 | 分别单独演示涨潮 / 钟声 / 提灯 |
| Tab | 在三种单独转场之间循环 |
| 左键 / Space / End | 正在演出时立即进入该段终态；增益进场跳到可选状态，确认段跳到已生效状态 |
| ← / →、Enter | 卡片可选时切换焦点、确认；也可以直接点卡片 |
| E | 对话中手动切换表情，80 ms 交叉淡化 |
| N | 对话中跳至下一个说话人，保留 150 ms 明暗交接 |
| F | 原地切换 A 宋体 / B 文楷组合；正文均用思源黑体衍生字库 |
| R | 重播当前演出 |
| P | 暂停 / 继续 |
| [ / ] | 0.25×、0.5×、1×、2× 播放速度 |
| M | 静音；声音触发日志继续输出 |
| H | 隐藏 / 显示校准面板；隐藏后可检查真正的全屏遮罩 |
| F5 | 重读 `motion.json` 并重播当前演出 |
| Esc | 退出 |

选择界面不会自动替玩家确认。点击跳过进场的同一次点击不会再选中卡片。对话默认完整演示三轮；点击会直接进入最后一句已全部显示的终态，N 用于单独检查换人。

## 参数

所有时长用毫秒，曲线均在 `motion.json`，修改后按 F5。尺寸、几何形状和占位文案在脚本中；没有用 Tween、系统时间或 Shader `TIME` 偷渡另一条动画时间轴。

| 分组 | 内容 |
| --- | --- |
| `common` | 进退场、卡片间隔、悬停、确认压缩/弹回、跳过门槛、呼吸 |
| `curves` | 具名曲线：`linear`、`smoothstep`、`cubic_in`、`cubic_out`、`cubic_in_out`、`back_out` |
| `boon` | 暗化、台词字速、卡片起始间隙、飞行、边缘闪光及导出时的自动操作间隙 |
| `dialogue` | 明暗交接、退后距离、表情交叉淡化、字速及自动阅读停顿 |
| `voyage` | 400 ms 航线与船标 |
| `transition` | 三种转场的各段时长；海浪幅度、空间频率、相位速度及固定颗粒强度 |
| `defeat` | 300 ms 减速、模拟速度 0.3、400 ms 全黑、提灯台词停留 |
| `capture` | 固定 30 fps，结束后保留的审阅尾帧 |
| `sound` | 采样率、音量、包络及每个提示音的音高/长度/衰减/泛音 |

`back_out.overshoot=0.08` 表示实际位移峰值过冲 8%，脚本由峰值反求 Back 系数；并非把 0.08 直接当作 Godot 的 Back 参数。默认进场 220 ms，退场 140 ms，卡片间隔 60 ms，悬停 90 ms / 1.04× / +15%，未焦点卡片亮度 65%；确认 60 + 120 ms。

**规格口径待校准**：`docs/ui-motion.md` 的通用全屏转场为 550–800 ms，但出航指定覆盖 600 ms、登陆指定退潮 800 ms。本原型保留这两个专用值，中间全遮 100 ms，涨潮往返共 1500 ms。单独钟声和提灯均为 700 ms（含 100 ms 全遮）。败北中的黑场按专用值保留 400 ms，不再叠加通用 100 ms。这里没有修改生产规格，也未据此断言手感合格。

## 30 fps 逐帧导出

在能打开 Godot 图形窗口的桌面终端中：

```sh
godot --path proto/ui_motion -- --capture --mute
```

会依次导出七段并退出：

```text
shots/t56/boon/frame_00000.png
shots/t56/dialogue/frame_00000.png
shots/t56/voyage/frame_00000.png
shots/t56/defeat/frame_00000.png
shots/t56/tide/frame_00000.png
shots/t56/bell/frame_00000.png
shots/t56/lantern/frame_00000.png
```

输出位置相对仓库根目录解析，不随终端 cwd 改变。每段另有 `manifest.json`：帧数、首尾采样时刻、完整参数快照、字体组合和声音时间点；顶层也有汇总。文件名的帧号除以 30 即演出时间。采样从 0 开始，包含向上取整后的最后一帧，因此帧数为 `ceil(时长 × 30) + 1`。即使机器保存 PNG 较慢，也不会改变演出采样时长。

默认参数的计划输出（待桌面实际导出确认）：

| 演出 | 含审阅尾帧时长 | 计划 PNG 数 |
| --- | ---: | ---: |
| boon | 4.590 s | 139 |
| dialogue | 4.124 s | 125 |
| voyage | 2.400 s | 73 |
| defeat | 3.150 s | 96 |
| tide | 2.500 s | 76 |
| bell | 1.700 s | 52 |
| lantern | 1.700 s | 52 |

导出里的增益自动依次悬停三张卡，再选第二张；交互运行不会自动选择。导出期间忽略输入，避免意外点击改变录制结果。重录只替换该演出目录中形如 `frame_数字.png` 的旧帧；不要把自有文件按这个模式命名放进去。

可选参数：

```sh
# 只导出一段；换字体、独立输出目录、隐藏校准面板
godot --path proto/ui_motion -- --capture --scene=boon --font=2 --out="$PWD/shots/t56-font-b" --clean --mute

# 从特定时刻开始交互查看，方便定位某个姿态
godot --path proto/ui_motion -- --scene=defeat --at=1.2 --font=2
```

`--scene` 接受 `boon/dialogue/voyage/defeat/tide/bell/lantern`。`--font=1/2`；`--quit-after=秒数` 可用于自动退出。`--headless --capture` 会明确报错并以 2 退出，不会假称生成图片。PNG 不含声音；声音日志保存在 manifest 中。

## 声音

十类占位提示音通过 `AudioStreamWAV` 在 Godot 中合成，不使用外部录音。触发时输出 `T56_SFX <演出> {cue, at_s, observed_s, skipped}`。`at_s` 为时间轴上的指定时间，`observed_s` 为帧采样时刻。跳过时停止在播声音，越过的旧提示只记日志、不集中补播。

- 立绘入场：起点；卡片：各自开始升起时；悬停：焦点变化时。
- 确认：开始压缩时；槽位：光束抵达时。
- 对话：每轮开始时用单音占位，不模拟配音。
- 出航：金线起点；涨潮：覆盖开始时。
- 败北：减速结束时钟响；400 ms 黑场结束时提灯提示。
- 单独转场：预览停顿结束、遮罩开始时。

## 验证与边界

```sh
test -f proto/ui_motion/README.md
godot --headless --path proto/ui_motion --check-only --script res://main.gd
godot --headless --path proto/ui_motion -- --self-test --mute
```

`--self-test` 核对七段跳过终态、选择保留、实际过冲、悬停终态、遮罩停顿、三份字体关键字形与合成音数据长度。它不替代 GPU 截图或听感检查。

本次沙箱可运行无头验证，但 Godot 图形启动卡在 macOS `hiservices-xpcservice / Connection invalid`，**未截图、未实际生成逐帧 PNG、未做真实键鼠与听感验收**。Lead 需在桌面运行上述导出，检查着色器、明暗层级、字体和手感后再校准规格。没有观察到足以判定规格时长/曲线“明显不好用”的视觉证据。

原型只演示任务卡列出的四类界面及三种转场，没有扩展胜利、结局或真正的战斗/地图逻辑。场景跳转是占位内容替换；提灯及钟波是原型图形。字体细节及授权见 [字体候选](../../docs/research/FONT_CANDIDATES.md) 和 [字体来源](fonts/NOTICE.md)。
