## 1. 世界尺度【确认】
- 地形体素 1×1×1，岛屿由 1 米见方的模块拼成
- 小兵半径 `r = 0.12 × scale`，胸口高 `0.23 × scale`，质量 `scale³`
- 升级后体型：`scale = 1 + (等级 − 2) × 0.06`
- 一格地形宽度大约能并排站 4 个兵；编队间距 `2r × 1.01 ≈ 0.24`，盾挨着盾

对本工程：我们的格子也是 1，但小兵画得太大（身高约 0.58），站位间距 0.42。要按上面的尺度缩小。

## 2. 架构：Agent + 组件 + 状态树【确认】

### 2.1 组成
一个小兵 = Agent 本体 + 一组组件（Body 移动、Brain 大脑、Shield 盾、Stun 眩晕、Ragdoller 击飞、Death 死亡……）。
组件在 Setup 时往 Agent 的状态树上挂自己的状态，并给状态注册 激活/停用/更新 回调。Agent 本身几乎不写行为。

### 2.2 状态树规则
- 每个状态有父节点、子节点、`exclusive`（互斥）标记
- 激活一个状态 → 自动激活它的所有祖先；若它互斥 → 停用所有互斥的兄弟
- 停用一个状态 → 递归停用所有子孙
- **空槽回调 OnEmpty**：当一个状态激活着、却没有任何互斥子状态激活时触发。用来"自动回到默认状态"，例如大脑没有动作时回到待机。这是整个系统不卡死的关键
- 每个状态记录切换时间戳，可以直接问"已经激活了多久"
- 每帧只更新激活着、且注册了更新回调的状态；树结构变化时才重建这个列表

### 2.3 Agent 的骨架状态
```
Root
├─ Spawned
├─ Life ── Alive* / Dead*                        (* = 互斥)
├─ AliveAndGrounded = Alive ∧ Grounded ∧ Spawned（由回调维护）
│   ├─ Exclusives ── Brain* / Acting* / Stun(倒地)* / Rise(爬起)*
│   └─ TriFlow（把自己写进势力场）
├─ Navigation ── Grounded* / Ragdoll(飞行)*
│   └─ Grounded ── Hop* ( Standing* / Stepping* ) / Slide*
├─ MoveAnimate（为真时由移动系统控制动画；攻击、拼刀、倒地时置假）
└─ ShieldCheck ── NoShield* / Shielding* ( SpearShield* / RangeShield* )
```
空槽回退链：Exclusives 空 → Brain；Grounded 空 → Hop；Hop 空 → Stepping；Brain 空 → Idle。

### 2.4 每个物理帧的顺序
1. 清零所有兵的威慑值
2. 对每个兵：通知它最近的敌人"有人靠近"（敌方据此施加威慑、触发反冲锋）
3. 对每个兵：
   - 从敌方势力场采样：最近敌人距离、方向、是谁
   - 从命令（小队目标）采样：到站位的方向、距离
   - 更新状态树（各组件在这里写 `walkDir`、`speed`、`velocity`）
   - 若着地：逻辑位置 += walkDir 限幅到 `dt × speed`；再加上外力；再按速度移动并处理撞墙/撞崖
   - 速度每帧乘 0.9（阻尼）
   - 血量每 60 秒回满（极慢回血）

## 3. 节拍【确认】
每个兵出生时取一个随机相位 `offset ∈ [0,100)`。判断"本帧是否到了 X Hz 节拍"= `floor((t+offset)/周期)` 是否和上一帧不同。
不用计时器，没有状态；每个兵的节拍自然错开。用到的频率：
- 8Hz：待机时找事做、更新邻居列表
- 4Hz：盾牌状态检查
- 2Hz：备战状态下的主要决策（冲锋/狩猎/回待机）

## 4. 感知：势力场 TriFlow【确认】
不搜索"最近的敌人"。每个阵营维护一张场，存在导航网格的顶点上，每帧在后台线程做一次：
1. **衰减**：所有顶点的"存在量" × 0.96，清空本帧距离
2. **写入**：每个活着、着地的兵把自己写进所在三角形的三个顶点（距离 = 到顶点的距离；存在量按重心坐标插值拉向满值）
3. **传播一步**：沿每条边，邻点距离 + 边长 若更短就接受（**每帧只扩散一条边**，所以信息像波一样传开）
4. **算方向**：每个顶点的方向 = 按邻点距离差加权的梯度

采样（小兵每帧做）：在所在三角形内按重心插值得到"最近敌人距离、指向敌人的方向、敌人是谁、是否危险、是否可打"。只信任方向一致、性质相同的顶点。贴着单边边界的三角形会把方向沿边界拉直，避免往墙里走。
附带得到"友军占比" = 我方存在量 /（我方 + 敌方），用来影响胆量。

对本工程：这同时解决了寻敌、绕路追敌和"敌人在悬崖那边"三件事。格子地形可以用同样思路：每个阵营一张格子场，每帧扩散一步。

## 5. 移动

### 5.1 逻辑位置和身体分离【确认】
- **逻辑位置**（导航网格上的点）每帧连续移动，速度 `maxSpeed`（剑兵 2.0 米/秒）
- **身体**（看到的精灵）不连续移动，而是一步一步"追"逻辑位置：
  - 站立时：逻辑位置偏离锚点 ≥ r，或偏离 > 0.3r 且几乎停住 → 开始迈步
  - 每一步开始时：把**当前逻辑位置**定为这一步的落点，身体从上一个落点线性插值过去
  - 步长时间 `= (步距 × 0.08 + 0.4) / lerp(maxSpeed, 2, 0.8)`；速度为 2 时约 0.2 秒一步
  - 步距不到 0.01 → 回到站立
  - 每步：累计行走距离、左右脚翻转、播放脚步声；步距 > 0.2 时扬尘
- 结果：身体比逻辑落后一步，步子大小随速度自然变化，转向和停步都很干净

### 5.2 动画与步伐绑定【确认】
走路片段 0.667 秒，包含两步。每帧把走路动画的播放进度直接设为：
`进度 = 步伐进度 × 0.5 + (左脚 ? 0 : 0.5)`
动画不自己播放，完全由步伐驱动。

### 5.3 速度修正【确认】
- 上坡/下坡：沿坡度方向，下坡最多 ×1.4，上坡最低 ×0.6【推断：slope 指向下坡】
- 朝向：移动方向与面朝方向一致 ×1.1，背对 ×0.7（后退变慢）
- 举盾挡箭 ×0.7，举盾对枪 ×0.8

### 5.4 速度（被打飞的那部分）与边界【确认】
- 受击加速度 = 击退 / 质量，沿攻击方向；且该方向上的总速度不超过这个值（连续被打不会无限叠加）
- 速度每帧 ×0.9，并去掉朝地面的分量
- 撞到**普通边界**：速度按边界反射，再减半
- 撞到**悬崖或岛的边缘**：若朝外速度 ≥ 2 → 进入击飞（掉下去）；否则沿边滑行
- 被击飞后若速度平方 < 0.0001 就停止滑行

### 5.5 朝向【确认】
"看向某方向"带转速（默认 720°/秒）和死区（默认 20°，举盾时 900°/秒、10°）。偏差在死区内不转，避免抖动。
精灵只有一个侧面，按朝向在镜头里的左右翻转。

### 5.6 草地【确认】
导航网格每块有一个"草量"；身体和影子的精灵颜色 alpha 通道写入草量，由着色器表现脚陷进草里。被击飞时草量强制设为 1。

## 7. 剑兵大脑【确认】

### 7.1 状态
大脑下的互斥状态：待机 Idle、备战 Ready、冲锋 Pursuing、狩猎 Hunting、攻击 Attack、拼刀 Clash、恢复 Recover；招架 Parry 由盾组件挂上。
大脑空了 → 待机。动作结束（Acting 停用）→ 重新评估。

### 7.2 体力
- 范围约 0–1，可以变成负数
- 待机：直接回满
- 备战：每秒 +1
- 冲锋：每秒 −0.3；体力 < 0 或冲锋后走了 > 2 米 → 累了，回到备战
- 攻击一次结束：−0.5（双手兵 −0.1）；还 > 0 才能接下一刀
- 拼刀结束：−0.5
- 恢复状态结束：清零
- 身边队友死亡：−0.3
- **邻居分摊**：每帧和最近的 3 个队友（1 米内）互相交换差值的 10%

邻居列表：8Hz 节拍时，从附近 1 米内的队友里轮询一个候选，维护按距离排序的 4 个，取前 3 个。

### 7.3 待机
体力回满。8Hz 节拍：能做专属动作就做；敌人 < 4 米 → 进入备战。否则执行小队命令（走向站位）。

### 7.4 备战（核心）
每帧：
- 走向站位：方向按距离缩放，乘以体力
- 被硬威慑：沿远离敌人方向退
- 被软威慑：后退量 = 威慑 × lerp(1.4, 0.9, 友军占比) × lerp(1.4, 0.9, 体力)。离站位 < 2 米时，后退方向限制在站位方向附近，不会被吓离阵地
- 没被威慑：敌人在 0.1–0.4 米内时稍微后撤，保持间距
- 面朝：敌人在命令方向的前方、或被威慑、或敌人 < 2 米 → 看敌人；否则看站位方向

2Hz 节拍：
1. **冲锋**：满足条件就冲，并向邻居广播。条件概括为"敌人正冲我、或敌人不危险；有体力；敌人在我前进路线上且离我的站位不比我远太多；敌人 < 1 米或我被威慑"。小队旗手在站位 1 米内不主动冲
2. 敌人 > 4 米 → 回待机
3. **狩猎**：敌人不危险（不在攻击状态），且离我的站位 < 2 米（旗手 1 米），或已贴近在前方 → 锁定它追杀
4. 能做专属动作就做

### 7.5 冲锋传播
发起者把冲锋广播给 3 个邻居；邻居若在备战、体力 ≥ 0、敌人方向和发起者大致一致（点积 > 0.1）、且不会因此离开站位 → 跟着冲锋，再继续广播。效果是**一个兵出击，整排跟上**。
**反冲锋**：被冲锋的剑兵在贴近时收到通知，若自己在备战、体力 > 0.2 → 广播；体力 > 0.3 时自己也迎上去。

### 7.6 狩猎
目标失效或不再值得追（离站位 > 3 米）→ 回备战。够得着就砍；够不着且直线可达就直冲过去；否则沿势力场方向走；都不行就回备战。
狩猎时若目标是正在瞄准我的弓手，持盾兵会先举盾逼近，而不是直接砍。

### 7.7 攻击
- 前提：在 Hop 状态（不在滑行、倒地）、活着且着地
- 攻击距离：两人半径之和 + `range`，`range = 0.7r`；约 0.32 米
- 出手：进入攻击状态、锁定目标、播放攻击动画、出手声。**同时通知对方的盾**：对方在备战或冲锋时会播放招架动画
- 攻击动画期间：持续朝目标走到刚好贴身的距离，转身面向目标
- 0.333 秒的命中帧：距离仍在范围内才结算；镜头震动 `0.03 × 伤害`
- 动画结束：扣体力；体力 > 0 就对当前最近的敌人再砍

### 7.8 拼刀
受击方正在攻击、攻击者就是自己的目标、两人的动画进度相差 < 0.4 → 判定拼刀：
- 这一刀伤害归零
- 双方都进入拼刀（播放拼刀动画、进入滑行）
- 互相施加一次只有击退的攻击（方向相反）
- 在两人胸口中点播放火花
拼刀结束扣体力 0.5，体力还有剩就接着砍。

### 7.9 盾
- **招架**：被剑砍时，若招架动画在生效、且攻击来自正面半圆 → 伤害归零，播放盾击特效。招架动画结束后，若攻击者还是最近的敌人就反击
- 没有招架时，若攻击来自正面 60° 内（点积 > 0.5）只改音效和特效，**伤害不减**
- 举盾挡箭：正面来的箭伤害归零（我方）或 ×0.05，眩晕 ×0.2；箭有 50% 插在盾上（盾上最多留 4 支）、25% 碎裂、25% 弹开
- 举盾对枪：伤害 ×0.2，眩晕 ×0.4
- 盾状态 4Hz 检查：被枪兵威慑 → 对枪；敌人 < 1 米且危险 → 放下盾（准备近战）；有远程威胁 → 挡箭；否则放下
- 举盾动画参数 0→1 的过渡速度为每秒 4

### 7.10 威慑
剑兵通知附近敌人时，距离在"贴身（两半径 + range）"到 1 米之间线性施加软威慑 1→0。威慑每帧清零重算，取最大值。被威慑的兵在备战里会后退（见 7.4）。

## 8. 冲击与倒地（Stun）【确认】
- 每次受击（活着、着地）：累积冲击 += 攻击的眩晕值 × 眩晕倍率 / 质量
- 累积冲击每秒衰减 0.25
- **阈值每次都重新随机**（不是每个兵固定一个）：
  - 累积 > rand(1, 3) 且可倒地 → 倒地
  - 否则累积 > rand(0.7, 1.2) 且可滑退 → 滑退
- 倒地时长 = `max(√累积, 2) × rand(0.5, 1)` 秒
- 倒地流程：播放倒下（速度² > 4 时一直重播第 0 帧，表现为被推着滑出去）→ 落地声 → 等倒下播完 → 坐地循环 → 计时结束 → 起身声 → 爬起播完 → 恢复。期间移动能力 ×0.1，处于滑行
- 倒地结束清零累积冲击
- 滑退：处于滑行，速度² < 0.04 时结束

## 9. 击飞、坠崖、落水（Ragdoll）【确认】
- 触发：攻击带"抛射冲量"，冲量 / scale² ≥ 0.9；或在悬崖边被推出去，朝外速度 ≥ 2
- 进入飞行：刚体球（半径 = r，质量 = 体积），初速度 = 当前速度 + 抛射（崖边推出时额外加 0.67 倍地面法线）。动画切到击飞循环，**从随机进度开始**；每次撞到东西再随机一次进度并扬尘
- 着陆：速度² < 1、碰撞法线朝上、在下落 → 尝试附着到导航网格（距离 < 0.63 米、飞行 > 0.2 秒）。附着成功：保留 20% 速度，播放爬起
- 摔死：撞击法向速度 > 12，或已死，或停住却附着不上 → 原地血溅并死亡
- 落水：高度低于水面 → 水花 + 落水声 → 直接移除

## 10. 死亡、尸体、血【确认】
- 血量 ≤ 0：特效换成血斩，碰撞半径减半，进入死亡状态，通知小队
- 死亡动画 0.583 秒（滑行状态，可被推动），结束时转成尸体
- **尸体不是活物体**：在地面上按"地面法线 + 背对方向 + 随机扰动"算出一个平躺的朝向矩阵，把最后一帧精灵按这个矩阵**平贴在地上**，并入同材质的批处理（每个材质一个批次，每岛最多 128 具）
- 死亡同时：地面血迹特效；在地形上**盖章式绘制血迹贴花**（半径 = 10r）；把血画进岛屿的涂色贴图
- 死亡状态 8 秒后彻底移除

## 11. 小队与编队【确认】

### 11.1 站位
- 玩家不是点任意地面，而是点**预先生成的站点 NavSpot**；每个站点有范围和朝向，一个站点一支部队。点被占的站点 → 两队交换，或把原占用者挪到附近、敌人少的空站点
- 编队：边长 `ceil(√n)`，沿站点较长的一边铺；**蛇形排列**（偶数行反向），人数不满时空位均分到两侧
- 站位间距 = `2r × 1.01`
- 站位放不下（出了导航网格）→ 互相推开迭代

### 11.2 动态换位
- **换中心**：每帧把"站点中心往敌人方向退一点"的位置换给英雄
- **换槽**：每帧轮询一个兵，和其他兵比较；若交换后"最大距离 + 两人距离之和"降低 1% 以上就交换。兵不需要提前分好位置，走着走着自己就排好了

### 11.3 到位转向
- 远距离移动、或转向超过约 45° 时：行进中先面朝来时方向
- 等第一个兵到站位 0.1 米内后，0.5 秒窗口内陆续标记到位
- 全部到位后，**逐个转向**站点朝向（加上地面法线的倾向），间隔 `0.2 秒 / 人数`，形成一个从头传到尾的转身动作

### 11.4 兵种协调器
小队协调器只负责整队行为：枪兵整队举枪/平枪、弓兵整队齐射、剑兵什么都不做（剑兵的协同完全靠 7.5 的邻居冲锋传播）。

## 13. 与本工程原型的差异 → 改动建议
| 项目 | 原型现状 | 按 Bad North 应改为 |
|---|---|---|
| 尺度 | 兵高约 0.58，间距 0.42，速度 1.0 | 半径 0.12，间距 0.24，速度 2.0，兵高约 0.45 |
| 移动 | 决策时定步长、带弧线跳 | 逻辑位置连续移动 + 身体按步追；步长时间公式见 5.1；弧线跳交给走路帧 |
| 状态 | 单层枚举 | 状态树（互斥、父子联动、空槽回退、计时） |
| 寻敌 | 每次遍历最近敌人 | 每阵营一张格子势力场，每帧扩散一步 |
| 血量 | 3–4 | 1（民兵 0.6），一刀死 |
| 冲击阈值 | 每兵固定，击飞即翻滚 | 每次受击重新随机；倒地 = 倒下→坐→爬起；翻滚只用于击飞/坠崖 |
| 被打 | 设定滑行速度 | 速度 += 击退/质量（单方向限幅），每帧 ×0.9；撞崖速度 ≥ 2 掉下去 |
| 体力 | 平均拉平，消耗小 | 攻击 −0.5、冲锋 −0.3/秒、拼刀 −0.5；只和 3 个邻居交换 10% |
| 协同 | 无 | 冲锋广播 + 反冲锋；威慑后退；招架 |
| 拼刀 | 判对方在 windup | 双方都在攻击且动画进度差 < 0.4 |
| 编队 | 3 列网格，一次性分配 | 蛇形方阵 + 每帧换槽 + 逐个转身 |
| 尸体 | 站立公告板显示躺倒帧 | 平贴地面的精灵，按地面法线 + 随机扰动 |
| 动画 | 自定帧率 | 12 帧/秒，攻击 0.6 秒、0.333 秒命中 |

注意：Bad North 里玩家是守方，以上是守方剑兵的逻辑。我们的玩家是进攻方，守方 AI 仍按 design.md 另做（小队协调器 + 个体状态树的两层结构不变）。
