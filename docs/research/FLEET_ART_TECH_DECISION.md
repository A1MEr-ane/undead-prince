# Fleet of the Fallen 局内美术技术决策：朝向镜头的 2D 精灵（2026-11-24）

依据：
- 用户的《Bad North 美术技术研究》任务书。
- 本仓库早先读 Bad North 解包源码整理出的 `docs/badnorth-art-spec.md`，证据等级 LOCAL_CONFIRMED。

更细的本地证据索引和原型实测，交给 T48（取证）和 T49（实验）。本文的结论在它们交付后复核。

证据等级沿用任务书：LOCAL_CONFIRMED / PUBLIC_CONFIRMED / OBSERVED / HYPOTHESIS / UNKNOWN。

## 第一屏：四个问题的直接回答

1. **Bad North 的角色在 360° 环绕时怎么表现？**
   - 正交镜头，固定俯角 30°，偏航可以任意转（LOCAL_CONFIRMED）。
   - 小兵身体是**只绕竖轴转的公告板**：所有精灵统一朝向"镜头前方的水平投影"，被击飞时沿父节点上方向（LOCAL_CONFIRMED）。
   - 只画一个侧面。左右由"兵的朝向 · 镜头右方向"决定，带 0.1 的滞回，翻转在着色器里做（LOCAL_CONFIRMED）。
   - 盾牌是**单独的 3D 网格**，挂在动画驱动的节点上。影子是贴地精灵，朝向地面法线。尸体平贴地面（LOCAL_CONFIRMED）。
   - 动作是精灵帧（12 帧/秒）。外观靠 UV 图采样部位贴图，和动作分离（LOCAL_CONFIRMED）。
   - 没有多方向预渲染图集。
   - 小结：身体永远朝向镜头，所以镜头转多少都连续；唯一的跳变是左右翻转，用滞回压住。
2. **柔和地形由什么产生？**
   - 手工模块按兼容边拼装（WFC 属于此类，PUBLIC_CONFIRMED）。
   - 柔和感主要来自烘焙的三方向天光体积、按顶点着色、片元后处理和水线处理（LOCAL_CONFIRMED，见 badnorth-art-spec 第 3–4 节）。
   - WFC 只负责"拼什么"，不产生柔和感。
3. **哪些适合更复杂的地形，哪些要重做？**
   - **适合**：公告板精灵、天光体积烘焙、贴地影子和尸体、涂色体积（血、焦痕）。这些和地形形状无关。
   - **要重做**：
     - 单一小岛加整块体积，换成按区域分块烘焙。
     - 城镇和城堡要处理"建筑挡住小兵"，Bad North 没有这个问题。
     - 平原不能靠岛屿边缘构图。
     - 地图结构改用"宏观布局 + 地表 + 建筑模块"的混合方案（任务书 5.2 节）。
4. **要不要换引擎、改架构？**
   - 不换。项目本来就在 Godot 4，现有原型已经实现了：正交 30° 镜头、竖轴公告板、带滞回的翻转、部位换色、天光体积。
   - 只做增量改进，见第 3 节。

## 1. 可行性：朝向镜头的 2D 精灵能否同时满足三件事

**结论：能。前提是固定俯角，并遵守一条规则：特效的形状在世界空间里定义，贴图可以是手绘 2D。**

| 需求 | 能否满足 | 做法 | 风险 |
|---|---|---|---|
| 360° 丝滑旋转 | 能 | 竖轴公告板每帧都朝向镜头，旋转天然连续。镜头改成连续方位角，鼠标拖动 + 帧率无关阻尼，不吸附 | 旋转时大量小兵的左右翻转同时发生，会"闪"。见下方第 1 条 |
| 飞行物（箭、弩矢、投石、冥火弹） | 能 | 飞行物是**世界空间对象**，按抛物线模拟。箭身用"绕速度轴转的公告板"（轴向公告板）：沿飞行方向拉长，绕自身轴转向镜头，任何方位都正确；拖尾用朝向镜头的条带 | 很低。Bad North 有弓手和独立的弹道数学（`ProjectileMath`，待 T48 取证） |
| 魔法特效 | 能，但要按类型选做法 | 分四类，见第 2 节 | 唯一不能做的：**画死在一张 2D 图里的方向性特效**，例如一张"向右喷火"的序列图，镜头一转方向就错了 |

需要处理的问题：
1. **翻转闪烁**。镜头转动时，凡是朝向和镜头右方向接近垂直的小兵都会翻面。处理办法：
   - 保留 0.1 的滞回。
   - 翻转改成约 0.08 秒的横向压扁再展开，读起来像"转身"，而不是瞬间镜像。
   - 镜头正在快速旋转时，滞回临时加大到 0.3。
2. **装备换手**。盾和剑画在精灵里，镜像后会换到另一只手。在 40–60 像素的尺度上可以接受，Bad North 的身体精灵也是镜像的。只有盾牌需要正面挡箭的读感时，才考虑像 Bad North 那样改成 3D 网格（T49 里对比）。
3. **俯角不能自由调**。公告板只绕竖轴转，俯角改了会让精灵变形（Bad North 开发者也这么说，PUBLIC_CONFIRMED）。第一版锁定 30°，只允许缩放和偏航。
4. **建筑遮挡**。城镇和城堡里，小兵会被屋顶和城墙挡住。处理办法：
   - 被挡住的部分用一层"透视剪影"（阵营色描边）画出来。
   - 镜头和焦点之间的屋顶自动淡出。
   - 这是 Bad North 没有、我们必须新做的部分。

## 2. 魔法与特效的四类做法（独立设计）
| 类别 | 例子（来自 docs/boons.md、units.md） | 做法 | 为什么旋转不出错 |
|---|---|---|---|
| 地面范围 | 圣水区、冥火痕迹（火径）、燃烧地面、钟声圈、落点预警 | 投到地形上的贴花，或者贴地平面加着色器 | 本来就在地面上，跟世界一起转 |
| 体积爆发 | 冥燃引爆、怨火爆、命中火花、烟、水花、灵魂火苗 | 朝向镜头的公告板序列图，手绘墨线加平涂，形状近似对称 | 圆团状的东西从哪个方向看都一样 |
| 方向性 | 引燃（扇形喷火）、冲锋拖影、光束、闪电链、号声波 | **几何体在世界空间里**：扇形平面贴地 + 沿扇形散布的公告板；光束和闪电用轴向公告板；冲锋拖影用条带 | 方向由世界坐标决定，贴图只负责质感 |
| 屏幕空间 | 命中停顿、镜头震动、受击闪白、选中描边、冥火能量条 | 着色器参数或 UI | 和镜头方位无关 |

画风要求：特效贴图和人物一样，用墨线加两档平涂（`docs/art-style.md` 第 1、4 节）。冥火是青绿色，日光和圣光是暖金色。辉光用加法混合，小兵用 alpha 裁切，避免透明排序问题。

## 3. 对当前局内美术方案的修改
替换 `docs/art-style.md` 第 4 节里"技术不改"的部分，改动如下：

| 项目 | 现状 | 改为 |
|---|---|---|
| 镜头旋转 | Q/E 每次 45°，平滑过渡 | **连续方位角**：中键或右键拖动自由转，Q/E 保留为 45° 快捷键。阻尼与帧率无关；角度不归一化，避免跨 0° 时绕远路 |
| 翻转 | 瞬间镜像，滞回 0.1 | 横向压扁过渡约 0.08 秒；快速旋转时滞回加大 |
| 小兵渲染 | 部位换色，没有描边 | 加墨线外轮廓（着色器按 alpha 边缘向外扩），两档平涂，阵营边光（亡魂青绿，王国暖金） |
| 盾牌 | 画在精灵里 | 先保持；T49 对比"3D 盾牌网格"的读感后再定 |
| 飞行物 | 无 | 世界空间弹道 + 轴向公告板 + 条带拖尾 |
| 魔法特效 | 只有尘土、血、火花几种 | 按第 2 节四类建特效库，统一手绘序列图风格 |
| 建筑遮挡 | 无（只有小岛） | 透视剪影 + 屋顶淡出（随城镇、城堡关卡一起做） |
| 地形 | 单岛 + 整块天光体积 | 先不动。地图会重新设计，定稿后按"宏观布局 + 地表 + 建筑模块"的混合方案重做，体积改为分块烘焙 |
| 大量单位 | 每个兵一个 MeshInstance3D | 500 个单位以上考虑 MultiMesh + 实例数据（帧号、外观、翻转）。T49 先测 50/200/500 个，再决定 |
