## 1. 风格特征（叙事层：立绘、UI、剧情插画、地图）
| 项目 | 要求 |
|---|---|
| 线条 | 手绘粗墨线，粗细有变化；外轮廓最粗，内部结构线细；转角利落 |
| 造型 | 修长、有棱角的风格化人体；表情鲜明，姿态有戏剧张力；剪影一眼可认 |
| 明暗 | 强明暗对比，阴影是大块平涂的形状，不用柔和渐变；一侧用饱和色勾轮廓光 |
| 色彩 | 每个角色一组有限主色，加一个标志光色；背景暗、角色亮 |
| 质感 | 绘画笔触可见，像数字厚涂加漫画墨线；不要 3D 渲染感，不要低多边形切面 |
| 光源语言 | 亡魂用**青绿冥火**作轮廓光和发光；王国用**白金日光**；旧部各有辅色（见第 3 节） |

## 2. UI 方向
> 2026-11-25：本节由 `docs/ui-motion.md` 取代（审美原则、Hades 2 的 UI 与转场学习、动效规格、对现有 UI 套件的评估）。
- 底色是深色：墨蓝、灰海色。装饰边框做成锻铁或青铜质感，带细金线，纹样来自海与钟（缆绳、船钉、钟纹）。
- **对话**：大幅半身立绘站在左右两侧，盖在暗化的场景上；对话框带名牌。立绘至少分 3 种表情。
- **增益选择**：每位旧部一种卡框颜色和一个图标。伯纳德是盾，玛蒂尔达是针线，奥斯温是石板，皮普是号角，渡魂人是灯。卡面写槽位、名称、效果，并标稀有度。
- **航海图**：羊皮纸海图叠墨线。难度颜色沿用 T29 的 5 档，但改成手绘色块。首领节点用该仇人的纹章。
- **战斗 HUD**：尽量少，只放部队卡（兵种图标加人数）和冥火能量条。

## 4. 局内战斗美术是否要改【议，Claude 建议】
> 2026-11-24 更新：用户要求确认"永远朝向镜头的 2D 精灵"能否同时满足 360° 丝滑旋转和魔法、飞行物特效。结论是能，具体修改见 `docs/research/FLEET_ART_TECH_DECISION.md` 第 3 节，那里的表格取代本节"不改的部分"。新增的改动：连续方位角镜头、翻转过渡、世界空间的飞行物和特效、建筑遮挡剪影。
**结论：玩法层的做法不改，渲染风格改。**

不改的部分：
- 3D 地形加朝向镜头的精灵。
- 部位编码换色的管线。
- Bad North 的镜头距离和操作。

原因：
- 小兵在屏幕上只有 40–60 像素高。Hades 那种高细节角色画法在这个尺寸看不出来。
- 叙事层（立绘、UI）和战斗层分开处理，Hades 自己也是这样：对话立绘远比局内模型精细。

改的部分（让两层看起来属于同一个游戏）：
1. **小兵加墨线描边**：着色器加 1–2 像素深色外轮廓，内部明暗改成两档平涂。
   - 这一条同时能解决用户之前"不够干净"的反馈：轮廓清楚、色块更少。
2. **阵营轮廓光**：亡魂一侧带青绿边光，王国一侧带暖金边光。远看靠光色就能分清敌我。
3. **色块减少到 3–4 块**：每个兵种只保留大色块，纹章、头发分块这类小细节删掉。
4. **地形改成暗调、高对比的绘画质感**：
   - 现在的淡彩海岛改为黄昏或阴天的灰海。
   - 冥火、日光作为画面里最亮的颜色。
   - 地表贴图加手绘笔触。
5. **特效改用手绘逐帧序列图**：冥火、爆燃、溅水，配墨线和平涂色。
6. **比例**：小兵保持 B 比例（2.3 头身，用户已定）。理由是远看可爱、好认。
   - 王子、首领这类具名单位，在局内用更大的精灵，比例向立绘靠拢（约 4 头身）。
   - 这一条需要用户确认。

验证方式：先让 Codex 画一张"局内战斗风格样张"（第 5 节第 1 批），和现在的截图并排对比，再决定是否改着色器和地形。

## 8. 人物形体与动作要拉开【定】
- 用户 2026-11-25：人物动作和形体需要更多变。
- 规则（写进 `art/prompts/characters.json` 的 `pose_rules`，以及每个角色的 `build` 和 `pose_v2` 字段）：
  - 每个人物的剪影都要能一眼区分：身高、胖瘦、宽窄、体态、重心各不相同。
  - 不要千篇一律的"英雄站姿"，多用坐、靠、跪、走、干活的姿势，表现这个人平时在做什么。
  - 手必须在做具体的事；头部角度和视线表达态度。
- 例子：
  - 伯纳德单膝跪着给头盔上油
  - 玛蒂尔达骑坐在木箱上咬断缝线
  - 奥斯温蹲在书堆上指着漂浮的图解
  - 皮普坐在船栏上甩着号角讲笑话
  - 伯爵脚搭在货箱上数钱
  - 国王病中瘫坐，一手遮眼
- 下一轮立绘重画（选定高级化方向之后）用 `pose_v2` 替换原来的 `pose`。三视图仍用中性站姿，但身高和体型要按 `build` 区分。
