## 2. 新世界观层级

### 2.1 底层：灵魂力量

**[已定]** 灵魂力量属于客观存在的超自然底层逻辑。永昼、亡灵相关力量与人类对其的认识，应从这层逻辑出发，而非反过来用永昼定义整个世界。

**[继承/待细化]** 旧稿已区分灵魂与肉体，灵魂可以被束缚、借冥火取得形体；躯体毁灭不必然意味着灵魂消亡。日轮秘印会消耗人格，耗尽者不能在当下历史复原。需要保留这组叙事前提，除非用户明确改动。

**[候选]** 以“灵魂本源”和“游离冥火”作为两个概念层次：

- 灵魂本源承载人格、记忆与自我；不可将其当作无代价的普通资源。
- 游离冥火是灵魂自然释放、死亡留下或可借用的能量，王子可在夜间收集，用于召唤、指挥和法术。
- 强制抽取灵魂本源可获得较多能量，但会损伤人格，持续消耗可使灵魂彻底消亡。
- 这能解释亡灵作战的常规资源使用不必等同于永昼的灵魂剥削，也能解释自然回复为何不能直接满足长年全国供能需求。具体生成机制、能量守恒、上限、日夜变化均未最终确定。

注意：Soul Power / Soulfire 只是当前可用的英文工作称谓；不自行引入最终术语表，不将“灵魂本源”“游离冥火”写成已经获准的正史名词。回溯的力量来源也不因此自动归入冥火系统。

### 2.2 运用：亡灵、宗教仪式、供能、拘束

同一底层力量可能被不同群体以不同方式运用。可探索以下关系，而非立即定为统一魔法技术树：

- 王子与军团：冥火召唤、军誓、指挥及法术。
- 日轮秘印：转化灵魂力量、维持光辉及供暖的秘密设施。
- 死亡与葬仪：灵魂的归宿、教会对亡者的处置、截留与释放。
- 渡魂人：维护/引导亡者的归途；与王子的契约是独立叙事关系，身份、能力来源与知晓回溯结果的方式继续保持神秘。

**[候选解释原则]** 灵魂力量不自带善恶属性；使用方式、同意与代价构成伦理差异。不要预设所有教会仪式是邪恶，也不要为王子的军誓预设正当性。

### 2.3 认知：人类如何解释这些现象

**[已定]** 永昼是宗教层面的展现；冥火不公开。公开神学与实际魔法原理不必一致。

**[候选]** 教会公开传播太阳庇护、神恩、冬季祝福之类的叙事。百姓知道永昼奇迹、地方供暖与仪式存在，不必知道其能量来自灵魂。普通教士可能只掌握维护仪式；少部分高级教士、知情王室成员、秘印研究者知道程度不一的真相。不要把所有教士都写成共谋者。

宗教应该具备独立的历史、信仰、仪式与死亡观；“终结永昼”并不逻辑上要求消灭宗教。上述是深化方向，具体教义、神祇是否真实、宗教与王室谁先出现、异端或改革派等均尚未定案。

## 3. 双日体系：自然昼夜与宗教奇迹并存

| 属性 | 自然太阳 | 永昼之日 |
|---|---|---|
| 本质 | 正常自然天体 | 人造/超自然的可见宗教奇迹（认可方向） |
| 运行 | 正常升落，昼夜与四季仍存在 | 可长期悬于王都上空；具体位置、大小待定 |
| 作用 | 自然光照、热量、昼夜节律 | 光辉与宗教象征；不要求承担直接供暖 |
| 活动规则 | 自然昼夜决定军团的活动窗口 | 不能等同自然太阳，不能导致最终王都攻城从规则上不可能 |
| 范围 | 世界自然环境 | 人造光主要影响王都及邻近区域；供暖网络可有更大范围 |

建议采用“自然昼夜与环境亮度是不同变量”的设计原则：自然太阳落下即进入亡灵可战斗的夜晚，即使王都受到永昼照耀，也能发生夜间攻城。人工光不能替代自然昼夜的判定；阴影、洞穴、天气和火把也不应自动改变世界时间状态（候选机制，需玩法验收）。

王都夜间视觉可保持苍白/金白神辉与外海深夜对比；远方星空、王都居民的生活习惯与第一次看到真正黑夜都可形成叙事表现。颜色、亮度、星空是否被遮没和居民是否从未见星星均未拍板。用户喜欢方案一不等于认可所有示例。

**旧稿修订提示：** “第一次日落”是结局工作名称，可保留其诗意，但字面含义应修正为人造日轮消失后王都第一次重新迎来完整黑夜/不再被人造光覆盖的自然日落。自然太阳在永昼时代一直存在升落；不能再写成自然太阳此前从未落下。

## 4. 永昼与全国供暖：光热分离，避免公开冥火工业化

### 4.1 光热分离（认可方向）

此前把永昼设计为悬空高温微型太阳，造成王宫和城市局部过热的逻辑问题。用户提出质疑后，认可将光辉与供暖分离。

工作模型：

```
灵魂力量（底层）
    └─ 秘密的收集、束缚、转化机制（日轮秘印等，细节待定）
         ├─ 王都：人造太阳，宗教奇迹的视觉展现
         └─ 各地：供暖与冬季庇护，由地方设施/仪式实现
```

不要把人造太阳画成依靠极高表面温度产生热辐射的恒星，也不要令其照到哪里就必然为哪里供热。可以保留局部暖光，但全国供暖的机制必须独立于可见光照强度和太阳的视距。

### 4.2 全国性影响

用户认为此方案能解释全国供暖，因此应将旧稿仅王城港区直接受益的设定列为需修订。全国性影响可表现为冬季港口防冻、城镇供暖、仓储与交通保障等；覆盖程度可因地区、季节、资源和设施而异。原有自然冬季、霜冠山脉、贫困岛屿、粮河和替代冬港等设定无需因此删除。

**[候选]** 中央源头和地方转化设施；也可采用仪式、秘印之间的超自然连接。不要把长距离输热管线、魔法电网、冥火运输船、冥火配额、透明能源市场等作为已确认事实。特别注意群岛地理：不能未经论证铺设贯穿全国的普通热水管网。技术细节应服务宗教氛围和保密制度，而非把国家写成公开的死灵能源工业帝国。

### 4.3 公开与秘密信息分层

| 公开层面 | 隐秘层面（工作方向） |
|---|---|
| 王都的永昼是宗教奇迹 | 人造光辉可能由灵魂力量转化 |
| 地方享受神恩或冬季庇护 | 供暖实际来源与秘印系统有关 |
| 教会掌握葬仪、祝祷及设施维护 | 部分葬仪被用来截留死者，供能代价被隐瞒 |
| 普通人看到的圣辉、圣火等现象 | 冥火以及消耗人格的核心机理 |

“圣辉”“日恩”“冬祷”“圣塔”等均是助手提供的候选公开称谓，不是最终术语。旧稿中的太阳教会、日轮秘印等名称先作为现有项目称谓使用。禁止在公开剧情、普通 NPC 对白、地图设施名称和前期说明中直接展示冥火是公共能源。玩家作为王子可以看到冥火战斗 UI；这与民间知道真实能源来源是两回事。

### 4.4 历史和道德困境（继承旧主线，修订范围）

保留旧设定的基本演变：严重寒冬迫使王室与教会寻找救灾手段；最初使用残余冥火及自愿奉献；临时奇迹成为长期繁荣基础；需求增长导致截留获罪者乃至无辜者的灵魂；政治与宗教既得利益使临时例外常态化。父王的例外授权、摄政对舰队叛国的构陷以及死者被送往秘印的计划可继续成立。

新变化：供暖利益不再只集中于王都，终止系统可能影响全国各地的普通人。这样会使抉择具有更大现实代价，但不要未经确认升级成必然全民冻死，也不要抹掉替代航运、粮储、燃料和过冬政策的价值。

**关键未解问题：** 既然光与热分离，熄灭宗教性日轮是否必须同时停止灵魂抽取和供暖？技术上可能允许分离。现有结局的“延续/终止永昼”究竟指人造太阳、剥削机制还是整套奇迹制度，需要后续明确。建议在既有二元结局结构内先保留“是否继续强制消耗灵魂”的实质抉择；研究替代供暖的可能，但不要擅增第三选项、结局数量或设定无代价解法。不可简单让关闭照明自动消灭全部供暖，也不可仅熄灯就宣称囚魂已获释。

## 5. 亡灵与回溯：两个确定边界

### 5.1 王子可以在白天活动，军队不行

这条规则解决亡灵王子如何参与外交、会面、调查、王都政务及登基结局的问题。不要再把“所有亡灵白天消散”写入通用规则。军队的白昼状态（休眠、无法实体化、返回舰队、收束于某处等）仍未确定，王子的日间战斗能力也不能仅从“可以活动”推出。用户在 Siege 中明确王子只能夜间率军作战，游戏战斗应服从这一限制。

与玩法接口：判定战斗时间用自然昼夜而不是人工照度；黎明结束战斗；夜间军团生成与冥火系统见玩法稿。王子在白天可以经历剧情，不等于玩家可以跳过攻城或无限白日作战。

待深化：白天军队如何随船跨海、受伤和死亡的灵魂如何归队、夜间召唤是否消耗人格、古战场及新亡灵为何加入、军誓是否覆盖自愿者和敌军亡魂、王子的特殊性来自何处。不要把助手给出的“王子白日只可行走谈话，所有冥火能力禁用”等细分建议作为用户已确认的设定。

### 5.2 回溯是私人契约

回溯只围绕王子与渡魂人之间的契约。永昼是宗教奇迹和王国制度；它不是该契约的必要条件。结束永昼不能直接导致回溯停止、王子消散或自动进入真结局。

旧稿已有的规则继续有效，除非另有更新：固定锚点在首次出征前；锚点前的谋杀、父王死亡、妹妹继位、基础军团复生不改写；失败或收潮时按契约回溯；王子保留亲历记忆，渡魂人知晓结果但其机制保留神秘；其他角色不保留旧周目记忆；实物证据与政治盟友需在当轮重新取得；真结局由王子自愿解约并封档。

仍待解决：渡魂人为何能维持回溯但不直接代替王子改写命运；解约条款为什么分阶段获知；回溯如何处理已耗尽灵魂与此前历史的道德代价。私人契约这一约束不能被误当成这些问题已经有答案。可以保持身份神秘，但需要稳定的行为边界，不要擅定神明、神力级别或时间旅行物理学。

## 6. 宗教、王室、纹章与视觉重新审视

旧设定：王室纹章为白底金色八芒太阳；太阳教会掌管正式葬仪和死亡登记；永昼王都的视觉以白色城墙与太阳象征为主。此前助手曾建议直接保留纹章，但用户明确提出要重新设计王室纹章和世界观，并进一步给出底层/宗教层关系，不能将旧纹章锁死。

建议设计顺序（工作方法，不是新增 canon）：

1. 先定义灵魂、死亡、力量与人类所知程度。
2. 明确宗教为何形成、如何看待死亡和自然太阳、与永昼的关系；确定宗教公开声称什么。
3. 建立王国及王朝的历史，明确太阳教会与王室的先后、盟约、权力关系。
4. 再区分王室纹章、王国标志、教会圣徽与永昼设施的标志。它们可以共享视觉母题，但不必相同。
5. 最后检查旧八芒太阳是否仍合适，或需要更独立的王朝象征。先保留既有美术资源，不因本稿批量废弃、出图或替换 UI。

候选取舍：若王室早于永昼，纹章可来自更古老的王朝、海上建国史或自然信仰；若永昼使王权合法性发生变化，纹章的历史演化可以体现这种变化。但这些只是可探索路径，不是用户已确认的建国史。避免将秘密灵魂抽取装置直接画到公开纹章上，导致所有人早就看到真相。

## 7. 叙事与结局影响审查

| 旧内容 | 新设定下的处理 |
|---|---|
