# 攻城原型的行动逻辑目标（2026-11-28）

- 【定】用户 2026-11-28：现阶段只需要解决行动逻辑，不再以胜率作为测试目标。
- 胜率扫描（T68、T77）搁置。已有数据保留作参考，其中待决的三项（弓兵优先默认值、"赢法不同"的判定、目标 2 的基准）一并搁置。
- 验收方式改为**行为场景测试**：在小场景里摆好单位，检查它们做的事对不对，而不是谁赢。
- 下面每一条都写成"在什么情况下，应该看到什么"，便于写成自动测试，也便于手玩时检查。

## 1. 所有单位都要满足
1. **不会无故站着**：
   - 有目标、目标可达时，不会停在原地超过 2 秒。T49 发现的"1.2 米站着不打"必须消失。
   - 只有正在交战、正在驻防、或被命令待命时才允许不动。
2. **不会来回折返**：同一个单位 10 秒内改换目标或路线不超过 2 次（目标死亡除外）。
3. **不穿墙、不穿崖**：只走得通的路；城门关着、墙没破时绕行或等待，不穿过去。
4. **拥堵会自己化解**：
   - 一个路口挤住超过 5 秒，至少一部分单位改走别的可达路线；没有别的路就排队，不能原地互相推挤卡死。
   - 拥堵只统计"想走却走不动"的单位。
5. **接战距离正确**：近战进入攻击距离才出手；拼刀、格挡、击倒按 `docs/badnorth-behavior-spec.md` 第 7 节执行。T61 发现的"拼刀进度差没取绝对值"要修。
6. **看得懂**：从单位的走向，能看出它要去哪。选目标遵循简单、固定的偏好，不随机乱跳。

## 2. 亡灵（进攻方）
| 兵种 | 应该看到的行为 |
|---|---|
| 普通亡魂 | 按部署点和集结点选路线；路线上遇到敌人就打；没有敌人就继续推进到战区目标 |
| 暗影刺客 | 优先走专属捷径（崖壁）；绕开大群守军，找弓兵和神职者下手；得手后找下一个后排目标，不恋战 |
| 缝合巨人 | 走向最近的可破墙段或城门，持续攻击直到打破；被围住时横扫；打破后继续向战区推进 |
| 集结指令 | 范围内的亡灵在 2 秒内转向集结点，到达后照常自主作战；指令有持续时间，结束后恢复原目标 |

- **路线和目标是两件事**（T68 的结论）：
  - 路线 = 走哪条路，由部署点或集结点决定。
  - 目标 = 到了以后打谁，由兵种偏好决定。

## 3. 守军（防守方）
1. **驻防**：没有威胁时待在自己的阵地上；阵地被攻击时就地抵抗，不离开阵地追出去太远（追击半径做成参数）。
2. **支援**：
   - 某个战区威胁超过阈值，守军从有余力的战区派兵，派出后按真实路径行军。
   - 出发地留下最低驻防。
   - 派出后有任务锁定时间，不因为威胁的小幅波动来回调动。
   - 一小股亡灵不能把整个预备队全部引走：派出的兵力和威胁大小成比例。
3. **弓兵**：在高地、城墙上射击；被近身时后撤到下一个阵地，或者换近战；不主动冲下高地。
4. **盾兵**：在阵线或城门口结阵挡住通路；不会被少量敌人拉离阵线。
5. **骑兵（预备队）**：机动支援，优先截击行军中的亡灵；不卡在窄路里。
6. **撤退**：主据点失守后，剩余守军放弃阵地，走最短路去港口登船；路上被攻击只躲不打。

## 4. 场景测试清单（每条一个小场景）
| 编号 | 场景 | 通过条件 |
|---|---|---|
| B01 | 1 名亡魂对 1 名盾兵，开阔地 | 3 秒内接战，没有站立超时 |
| B02 | 10 名亡魂挤过城门 | 没有永久卡死；有其他路线时一部分改道 |
| B03 | 城门关闭，墙没破 | 没有单位穿墙；亡魂改去薄弱段或等待 |
| B04 | 巨人对可破墙段 | 巨人走到墙下并持续攻击直到破口，然后通行重算 |
| B05 | 刺客对高地弓兵 | 走崖壁捷径，先杀弓兵，不和盾兵纠缠 |
| B06 | 小股亡灵佯攻战区 A | 守军派出的兵力和威胁成比例；战区 B 保留最低驻防 |
| B07 | 威胁在阈值附近波动 | 守军不来回调动（任务锁定生效） |
| B08 | 弓兵被近身 | 后撤或换近战，不站着被砍 |
| B09 | 集结指令 | 范围内单位 2 秒内转向；到达后恢复自主 |
| B10 | 攻占主堡 | 剩余守军走最短路去港口登船，不反击 |
| B11 | 山洞权限 | 只有有权限的单位能走山洞；出口拥堵会排队 |
| B12 | 拼刀和格挡 | 按规格第 7 节触发，进度差计算正确 |

每个场景都要能无头运行，并能开窗口回放观看。
