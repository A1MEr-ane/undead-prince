# 设计笔记（迁移自 claude.ai 对话，2026-11-23）

标注说明：【定】= 用户说过或明确决定；【议】= Claude 的建议，未经用户确认；【待定】= 用户明确说之后再定。

## 1. 定位
- 【定】切入点是质感，不是玩法；即使玩法和别人相似，也可以靠美术风格做出区别
- 【定】简单：界面不复杂，玩家要做的事情不多；带即时决策
- 【定】先做单机
- 【定】早期提过的参考：《土豆兄弟》的割草爽感、《元气骑士》、《以撒》的感觉

## 2. 参考游戏分工（2026-11-23 最新版本）
| 参考 | 借鉴什么 |
|---|---|
| Bad North | 【定】局内战斗、建模，按它的标准做 |
| Kingdom Rush | 【定】大地图、王子复仇的剧情框架（维兹南的复仇） |

## 3. 故事
- 【定】王子被人陷害，率领亡魂大军向自己的王国复仇
- 【议】死亡回到亡者据点，剧情随每局推进（Hades 式）；每个区域由一名参与陷害的贵族镇守，击败后揭开一部分真相
- 【议】烧毁民房换魂魄资源，但烧的是自己的子民，可以作为影响结局的隐藏数值
- 【待定】世界观、文化背景、美术题材

## 4. 局内战斗（进攻方）
- 【议】每场分两段：部署阶段（暂停，看清守军后选登陆点或进攻点）→ 即时阶段（慢动作下调度）
- 【议】守方要有动态来制造即时决策：警钟增援、传令兵去点烽火、侧翼援军
- 【议】胜利条件是夺旗或夺祭坛，不要求全歼
- 【议】招魂：杀死的守军起身成为己方亡魂兵（实现人口滚雪球和割草感），需要上限或衰减
- 【议】操作上限：同时最多 4 支部队；只有"选队 → 点格子"和每队 1 个技能；下指令时时间变慢
- 【议】王子技能可以起到海岛奇兵里炮艇能量的作用

## 5. 构筑（【待定】，先不实现）
用户列出的维度：强化兵种、人口、数值、特殊机制、道具、特质组合。
【议】按 Hades 2 的结构组织：
- 槽位按"军队的动作"设：步卒、弓卒、枪卒、登陆或进攻、招魂，加被动；每个槽只能装一个祝福
- 赐福者是几股亡魂势力，每股对应一种标签和一种状态（例如水、火、铁、疫、王权）；有双势力组合，有同标签门槛效果
- 六个维度的位置：特殊机制 = 祝福；特质 = 标签门槛加局外特质；数值 = 稀有度和升级；强化兵种 = 分叉升级；道具 = 出发前带的信物；人口 = 招魂相关祝福
- combo 优先改写战场动作（推、烧、落水、高地），让效果直接在画面上看得见，少做纯百分比加成

## 6. 美术方案
- 【议，基于 Bad North 拆解】3D 地形模块 + 2D 小兵精灵（朝向镜头、单侧面、左右翻转）
- 【议】小兵精灵存部位编码，着色器套部位贴图上色：王国军、亡魂军、等级换装都共用同一套帧
- 【议】每个兵种约 40–70 帧，覆盖全部动作
- 【议】让小兵各不相同的四层随机：外观部件、动画相位和播放速度、行为参数（反应延迟、胆量）、物理结果（击飞、倒地姿势）
- 【议】血迹和尸体留在战场上；命中时停顿几帧；待机时有小动作；打赢后欢呼
- 【议】风格样张：在实际镜头距离下截图，检查三件事：敌我和兵种能否一眼分清、小兵是否各不相同、质感是否成立

## 7. 风险
- 守方 AI 是最大的工作量（Bad North 的进攻 AI 很简单，不能照搬）
- Hades 式的剧情量很大：小团队建议纯文字，NPC 控制在 4–5 个
- 招魂滚雪球会稀释紧张感，需要早做数值测试
- 同屏一两百个单位以内不需要专门优化，超过就要做实例化
