## 0. 一句话总结
**全场没有实时光照，也没有实时阴影。** 所有物体用不受光照影响的着色器，亮度来自岛屿生成时烘焙的"三方向天光体积"，再按太阳方向、时段配色和径向雾实时合成。小兵是带 UV 映射的二维精灵，同一套帧换一张部位贴图就是另一个兵种或阵营。

## 1. 镜头【确认】
- **正交投影**，俯角固定 30°，绕岛旋转（偏航可调）
- 缩放 = 改变正交尺寸；岛宽决定默认缩放
- 选中部队进入慢动作时：缩放到 0.975 倍，并把镜头往选中英雄方向拉一点（平滑过渡，用不受慢动作影响的时间）
- 公告板精灵高度乘 `1 / sin(60°) ≈ 1.155`，补偿俯视造成的竖向压缩

对本工程：现在用的是透视镜头、俯角 50°，应改成正交 30°。

## 2. 小兵精灵

### 2.1 精灵存的是"UV 图"，不是颜色【确认 + 推断】
- 精灵图集里每个像素：**R、G = 部位贴图里的坐标**（画面上是红绿渐变），**B = 明暗偏移**，**A = 不透明度**
- 着色器：`颜色 = 部位贴图[本兵外观的起点 + 精灵.RG × 单格大小] × (1 + 明暗)`
- "本兵外观的起点"写在精灵实例的顶点色里（部位贴图按 256 格划分，顶点色 R、G 是格子的行和列）
- 部位贴图自己也有 alpha，可以让某些部位不显示（例如有的兵没有头盔）
- 精灵边缘是柔和抗锯齿的，**不是像素画**；着色器用屏幕导数做边缘抗锯齿，配合 alpha-to-coverage【推断：精灵是从三维模型渲染出来的 UV 通道】

和我们原型的区别：我们存"部位编号"，一个部位只能一种颜色；它存"坐标"，部位贴图里可以画花纹（盾徽、衣服褶皱、金属高光），而且花纹会跟着动画走。

### 2.2 公告板【确认】
- 只绕竖轴转：所有公告板统一朝向"镜头前方的水平投影"。父节点倾斜时（被击飞的身体）沿父节点的上方向
- 左右翻转：看"兵的朝向"和"镜头右方向"的点积，**带 0.1 的滞回**，避免在侧面来回抖动
- 翻转也在着色器里做：看法线在镜头右方向上的正负

### 2.3 精灵受光【确认】
小兵不是纯平涂。顶点着色器按小兵的世界位置去查地形的天光体积（第 4 节），得到所站位置的明暗，再混合：
- 草色：按季节从"草色渐变条"里取
- 雪：按雪量混成雪色
- **脚陷进草里**：精灵下面 20% 的高度按草量混成草色 × 0.8（草量从导航网格那一块地读出，写进精灵颜色的 alpha）
- 镜头 Z 方向的微调：亮度 ×(1 + 0.03 × 视线分量)

### 2.4 受伤和血【确认】
- 血量写进精灵颜色的 B 通道：`B = 1 − 血量比例`
- 带血版本：采样一张**血迹噪声贴图**（坐标稳定，基本跟着身体走），`血量 = 噪声 × 2 + (√受伤 × 2 − 2) − 明暗`，超过就把部位色乘上血色。血是从噪声里"长出来"的，越伤越多，形状固定不闪
- 选中：整体往选中色偏；悬停：变亮 0.2，轮廓加宽

### 2.5 帧和动画【确认】
- 帧率 12 帧/秒，每个兵种 37–71 帧
- 每个兵是几个精灵的组合：身体（动画）、盾牌（单独的三维网格，挂在动画控制的节点上）、武器挂点、影子（单独精灵，贴地面法线旋转）
- 盾上插着的箭会"盖章"进盾的精灵里，最多 4 支

### 2.6 影子【确认】
- 每个兵一个影子精灵，朝向 = 地面法线 + 向上，迈步时在起点和终点的法线之间插值
- 影子颜色 alpha 也写入草量
- 被击飞时影子关掉

### 2.7 尸体【确认】
- 尸体用单独的着色器，**平贴在地面**：朝向 = 地面法线 + 背对方向 + 随机扰动
- 同一种外观的尸体合并成一个批次，每岛最多 128 具
- 死亡时：地面血迹特效、盖章式血迹贴花（半径 10r）、把血写进地形的涂色体积（第 5.4 节）

## 3. 地形网格

### 3.1 模块【确认】
- 岛屿由 1×1×1 的手工模块用 WFC 拼成，模块库约 935 个网格
- 每个模块拆成几个部件：**岩体**（灰色，崖壁和地表）、**导航面**（可走表面，同时用来寻路）、**水**、**瀑布**
- 岩体用不受光照的体素着色器；颜色在顶点色里

### 3.2 小尺度遮挡【确认】
每个模块网格离线烘焙顶点遮挡：每个三角形向法线半球发 16 条长 1 的射线，被挡住按命中距离变暗，平均到顶点。结果写进顶点数据，着色器里占亮度的 40%。

### 3.3 崖壁岩层【确认】
- 一张 1×128 的随机条带贴图，按世界高度 × 0.1 查：每个条带随机"深 / 浅"、随机灰度
- 一张平铺噪声贴图打散条带边缘（用屏幕导数做抗锯齿）
- 结果是一个灰度值，在"浅岩色 0.7"和"深岩色 0.3"之间取；深色出现的概率随战役进度变高（越往后岛越阴沉）
- 崖壁的最终颜色 = 灰度 × 光照色，**不是贴图上色**

### 3.4 水线【确认】
在水面高度附近把岩体压暗到 0.9，形成一条细的湿痕线（同样用导数抗锯齿）。

### 3.5 树【确认】
- 三维树干 + 精灵树冠（合批），种下时随机偏航、按地块半径缩放
- 树会往体素空间里加"遮挡量"，所以烘焙天光时**树会让周围地面变暗**
- 树影是贴地精灵：靠近边界时朝向沿着边界方向
- 树和杂物用"Grass"着色器：两色渐变（主色 → 第二色）、法线向外混合使明暗柔和（NormalBlend 0.5）、风吹弯曲和抖动、内外描边可选（描边亮度 ×0.8）

## 4. 光照：三方向天光体积（核心）

### 4.1 烘焙【确认】
- 岛屿生成后，对每个体素角点烘焙一次，存进一张三维贴图（用二维贴图切片模拟）
- 从角点发出一棵分层射线树（半径 5 格）。叶子方向带三个"光瓣"：
  - R = 从 +X 侧来的光：`clamp(dot(方向, normalize(1, 0.2, 0)))^5`
  - G = 从正上方来的光：`clamp(方向.y)^5`
  - B = 从 −X 侧来的光：`clamp(dot(方向, normalize(−1, 0.2, 0)))^5`
- 射线穿过的体素按被覆盖的面积衰减，完全在实体内就为 0
- 结果做伽马处理后写入。另有一张法线体积（每个体素的平滑法线和开阔度）

### 4.2 着色（每个顶点）【确认】
1. 顶点位置沿法线外推 0.4（稍微混一点切线），三线性采样天光体积，得到 RGB 三个光瓣
2. 太阳方向只在 X-Y 平面里转（一天转一圈，东升西落）。亮度 = 三个光瓣 × 太阳方向在 +X、上、−X 的分量，按分量和归一化
3. `亮度 = 0.6 × 上一步 + 0.4 × 模块顶点遮挡`
4. `环境色 = lerp(草色 × 最暗环境色, 最亮环境色, 亮度)`
5. 朝阳的面再加：侧光色 × 云量系数 × 法线对太阳的匹配度
6. 闪光（雷电、爆炸）：按方向加一层闪光色 × 0.6
7. `顶点颜色 = 上面结果 × 模块顶点色`

为什么这样做：没有实时阴影，但缝隙、崖底、树下都有柔和的暗部；太阳在动时整岛明暗跟着变；三个光瓣只要一次烘焙。

### 4.3 片元后处理（每像素，在地形着色器里）【确认】
- 去饱和：按"亮度 = 0.2R + 0.7G + 0.1B"往灰色拉，力度跟云量走
- 调色：往一个时段颜色插值（LutLerp，强度约 0.45–0.65）
- 径向雾：按到岛中心的水平距离，在内径和外径之间混入雾色
- 小兵着色器里没有雾，岛中心没有雾

### 4.4 时段配色（正午附近，参数记录）【确认】
时段由一组渐变定义，以下取正午附近的关键色（未乘强度）：
| 参数 | 颜色（RGB 0–1） | 强度 |
|---|---|---|
| 最暗环境色 | (0.26, 0.22, 0.26) | × 2.4 |
| 最亮环境色 | (0.83, 0.87, 0.90) | × 2.4 |
| 侧光（太阳） | (0.63, 0.55, 0.42) → (0.26, 0.22, 0.16) | × 5 |
| 顶光 | (0.45, 0.36, 0.22) | × 5 |
| 雾色 | (0.75, 0.75, 0.75) – (0.8, 0.8, 0.8) | |
| 云色 | (0.77, 0.77, 0.77) | |
| 镜面（水）色 | (0.51, 0.63, 0.66) – (0.58, 0.68, 0.69) | |
| 清晨、黄昏 | 环境偏蓝紫 (0.18, 0.22, 0.35)，雾偏暗蓝 (0.23, 0.26, 0.29) | |

读法：基调是冷灰蓝的环境光 + 暖黄的侧光，暗部偏紫灰；整体低饱和，雾是浅灰。

## 5. 环境

### 5.1 海和雾【确认】
- 海面不是水体渲染，而是**雾平面**：一张雾贴图随风向和时间滚动，用正弦在两个通道间摆动，再按云量阈值显示
- 岛的边缘按半径渐隐到雾色：内径 = 岛半径 × 0.5 + 1，外径 = 岛半径 × 1.2 + 2
- 雾粒子在边缘飘
- 水面模块单独着色；船尾有尾迹（泡沫贴图 + 渐变条）；瀑布有自己的着色器和水花

### 5.2 天气和季节【确认】
- 天气状态：云量、雨量、雪量、积雪、风、雷、温度；按关键帧插值
- 季节：一条"草色渐变条"（64 像素），按年份进度取色；地表和小兵脚下的草都用它
- 积雪按雪量把颜色混成雪色；霜冻 = clamp(0.5 − 温度)

### 5.3 粒子和小特效【确认】
- 尘土：池化 256 个，迈步距离 > 0.2 或击飞落地时生成
- 血斩、血溅、血迹、命中火花、盾击、拼刀火花、水花、烟、火都是复用的特效池
- 命中时镜头震动 = 0.03 × 伤害

### 5.4 地形涂色体积（血和焦痕）【确认】
- 整个战役共用一张三维涂色贴图（二维切片），每格存血量（R）和焦痕（G）
- 死亡时在死亡位置往上 0.25、大小 0.5 的盒子里**累加**血量；房子烧毁时加焦痕
- 地形着色器在顶点里三线性采样，片元里用平铺噪声做阈值：`涂色量 + 噪声 ≥ 1.01` 时完全染色，否则部分着色
- 血迹跨回合保留，同一个岛打得越久地上越红

### 我们自己的素材方案【议】
素材不能取用原作，帧需要自己做。最接近它的做法：
1. 用 Blender 做一个低模剑盾兵并绑定骨骼，渲染侧面动画；渲染时输出"部位 UV"通道（RG）和明暗（B），得到和它同格式的精灵
2. 部位贴图手绘：阵营、等级、亡魂版本各画一格
3. 过渡期继续用程序化火柴人，但改成输出 UV 格式，先把着色器和光照管线搭起来
