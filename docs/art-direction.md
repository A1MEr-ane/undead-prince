# 美术方向：可爱比例规范（草稿，2026-11-24）

标注：【定】= 用户确认；【议】= Claude 提案，待用户选。
来源：用户反馈"腿不够短""要有可爱的感觉""小短腿比较可爱"（【定】）。

## 1. 目标感受
- 小、圆、结实，像桌面上的玩具兵；远看是一团清楚的剪影，近看有表情。
- 战斗残酷（一刀死、血、落水），但角色本身可爱——反差是质感的一部分。
- 王国兵整齐可爱；亡魂兵松垮滑稽可爱（不恐怖、不恶心）。

## 2. 比例（单位：总身高 = 1.0，含头盔）
| 项目 | 现状（盾兵 v4） | 方案 A：2.0 头身 | 方案 B：2.3 头身 | 方案 C：2.6 头身 |
|---|---|---|---|---|
| 头（含盔）高 | 0.34 | **0.50** | **0.44** | **0.38** |
| 躯干（肩到裆） | 0.42 | 0.32 | 0.34 | 0.36 |
| 腿（裆到地，含脚） | 0.24 | **0.18** | **0.22** | **0.26** |
| 头宽 / 肩宽 | 0.34 / 0.45 | 0.52 / 0.46 | 0.46 / 0.44 | 0.40 / 0.43 |
| 脚长 | — | 0.16（大脚） | 0.14 | 0.12 |
| 手 | 方块拳 | 圆手套，直径 0.12 | 0.11 | 0.10 |
【议】推荐 **B（2.3 头身）**：腿明显短、头大，但躯干还放得下外衣、腰带、纹章，武器和盾的动作也有空间；A 最可爱但躯干太小，盾会挡住几乎全身。由用户看对比图选。

## 3. 形体规则（所有兵种通用，【议】）
- **头**：接近球形，下巴圆；眼睛是两颗竖椭圆黑点，位置偏低（在头高 40% 处）；无鼻或极小鼻；王国兵有粗眉，亡魂兵眼眶里是冥火。
- **躯干**：梨形/桶形，腰不收；外衣下摆略外张，盖住大腿上半。
- **腿**：短粗圆柱，无明显膝盖；两腿间距窄；**大脚**，鞋头圆。
- **手**：无手指的圆手套形；手臂短，自然下垂时手到腰带以下一点点。
- **装备**：武器、盾相对身体放大（盾直径约身高 0.40，剑长约 0.45），但不挡住头和躯干上半（侧视必须露出脸、外衣、迈步的脚）。
- **线条**：低多边形但边角圆润（倒角），避免尖锐长条；头盔像倒扣的碗。
- **动作**：小碎步（腿短 → 步幅更小、频率更快）；待机有呼吸起伏和偶尔眨眼/歪头；受击和倒地动作夸张一点（Q 版允许更大的挤压拉伸）。

## 4. 精灵规格的连带变化
- 图集帧仍为 64×64；人物站姿高度约占格高 60–65%（比现在矮），头更大所以面部像素更多。
- 游戏内单位世界高度保持约 0.40–0.45（`Unit.QUAD` 视比例微调），保证一格地站 4 个兵的密度。
- 部位贴图分区不变（16 区），新增"脸"细节画在 skin 区的头部范围。

## 5. 流程
1. 比例对比图（Codex 出图）→ 用户选方案
2. 按选定比例出三视图（Codex 出图）
3. Blender：把建模脚本改成**通用 Q 版身体模板**（头/躯干/短腿/手脚为参数化部件），兵种只定义装备、配色和少量比例偏移
4. 盾兵按新模板重建 → 游戏内截图 → 用户验收 → 再推广到其他兵种
