## 1. 新的世界层级
```
底层：灵魂力量（客观存在）        【定】
 ├─ 运用：王子与军团的冥火、教会的秘印、葬仪与截留、渡魂人的引渡
```

### 1.1 灵魂力量【议：概念分层】
- **灵魂本身**承载人格和记忆，不能当作无代价的燃料。
- **残余冥火**是死亡留下、灵魂自然逸散的能量。夜里没有日光时，它能凝成形体；日光下会散开。
  - 这一条就是"亡灵军队只能在夜晚作战"的原因【定】。
- **强行抽取**灵魂本身能得到多得多的能量，但会磨损人格，持续抽取会让灵魂彻底消失。秘印就是这样运转的（沿用 canon）。
- 结果是两套用法：
  - 王子用的是残余冥火，量小、只在夜里有效。
  - 秘印抽的是灵魂本身，量大、不受昼夜限制、代价是人。
  - 这就解释了为什么王国不满足于残余冥火，以及为什么冥火回复不能替代秘印。

### 1.2 战斗中召唤的是什么【定】
- **旧部**（伯纳德、玛蒂尔达、奥斯温、皮普，以及最初的舰队亡魂）是**有名有姓的灵魂**，受军誓约束。这一条沿用 canon。
- 战斗中用冥火**原子化生成**的士兵是**回声**：残余冥火借用死者生前的形与技艺凝成，没有完整人格，天亮即散。
  - 生成回声不消耗任何人的灵魂，所以玩法上的"大量生成、大量牺牲"不构成剥削。
- 推论：
  - 军誓、自由意志、"解除军誓"这些伦理问题只涉及旧部，和战斗生成无关。canon 的三次决定不受影响。
  - "以战养战"（击杀获得冥火）在设定上成立：死者留下的残余冥火可以被就地收拢。
  - 招魂（玛蒂尔达）可以解释为把新死者的残余冥火凝成回声，而不是绑架灵魂。

## 2. 双日：自然昼夜与人造永昼【方向，用户认可方案一】
| | 自然太阳 | 永昼之日（人造） |
|---|---|---|
| 运行 | 正常升落，有四季 | 悬在王都上空，长明 |
| 作用 | 自然光热，决定昼夜 | 宗教奇迹的光，**不负责供暖** |
| 和亡灵的关系 | 日出时军团消散，是战斗的倒计时 | 人造光**不算白天**，王都在自然夜里照样能打 |

- **光热分离**【方向】：
  - 永昼之日只发光，不是高温天体，所以王宫不会被烤化。
  - 供暖靠各地的设施和仪式实现，详见第 3 节。
- 【定】永昼之日的样子：
  - 一轮苍白的环形光盘，悬在王都主塔之上，不刺眼、没有热度。
  - 夜里王都被均匀的白金光照着，没有影子的方向感，城外是正常的黑夜。
  - 王都居民习惯了"夜里也亮"，但不是没见过星星；城外的人每天都看得到真正的夜。
- 【议】为什么秘印必须一直挂一轮看得见的太阳：
  - 那是教会和王室"与神立约"的证据，王权的合法性就建立在它上面。
  - 熄灭它，等于公开承认盟约失效，这对教会是灭顶之灾。
  - 所以即使光和热在技术上能分开，当权者也不敢只关光、不关热。
- **E08"第一次日落"的新含义**【定方向】：
  - 自然太阳一直在升落，所以这里指的不是太阳第一次落下。
  - 永昼之日熄灭后，王都第一次迎来完整的黑夜：自然日落之后，天真的黑了，第一次看到满天星。
  - 结局名保留。

## 3. 全国供暖与保密【定】
- 【方向】供暖覆盖全国，不只是王都港区：港口防冻、城镇取暖、粮仓和冬季航运都受益。覆盖程度按地区和财富不均：
  - 王都和富庶城镇最暖。
  - 外岛、贫村、盐沼只分到一点"冬恩"。
  - 这个不均本身就是政治问题，地方领主靠争取冬恩换取忠诚。
- 【议】传播方式（避免写成公开的能源工业）：
  - 各地教堂里有一座**圣火龛**。冬至时，教士从王都请回"圣火"种子点燃，整个冬天由龛供暖。
  - 公开说法："日之恩泽随圣火下乡"。
  - 实情：圣火龛里的火是秘印分出的灵魂之火，熄了要再"请"，所以地方永远依赖王都和教会。
  - 群岛之间靠船运送圣火，这和"葬运免检"那条暗线（canon）可以合并：同一条船，去程运圣火，回程运死者。
- **公开与隐秘分层**【定方向】：

| 公开 | 隐秘 |
|---|---|
| 王都的永昼是神迹 | 光由灵魂转化 |
| 冬天的圣火是神恩 | 圣火靠秘印抽取的灵魂之火 |
| 教会主持葬仪、登记亡者 | 部分葬仪截留死者，送往秘印 |
| 亡灵是天谴 | 亡灵只是残余冥火凝成的形体 |

- 普通 NPC 的对白、地图设施名称、前期说明里都不提"冥火是能源"。玩家看到的冥火 UI 属于王子的视角，不是世人的常识。
- 知情范围【议】：
  - **完全知情**：大主教安塞姆、先王阿尔德里克、宰相沃尔特、少数秘印守护教士。
  - **部分知情**：女伯爵阿格尼丝只知道"冬恩要靠王都"。伯爵罗德里克知道"葬运免检"，以为船上运的只是普通货物。
  - **不知情**：元帅休、普通教士和百姓。
  - 奥斯温查葬仪账目查到了一半，所以被处死。

## 4. 王子与军团【定】
- 王子白天可以活动：外交、会面、调查、王都政务、登基结局都成立。
- 亡灵军团白天不行。
- 【定】军团的白天：日出时回声散去；旧部和最初的舰队亡魂随"收潮"沉回舰队的船壳里，白天整支舰队沉在水下航行，入夜再浮起。
  - 这正好是游戏名 Fleet of the Fallen 的画面：一支沉没的舰队，每晚浮出海面。
  - 也回答了"军队怎么渡海"：沉在水下，跟着王子的船走。
- 【议】王子白天不能施展战斗力量，冥火在日光下用不了。他白天只是一个半边脸是骷髅的人，这对外交场面也是一个好处：他没有威胁力，只有身份。

## 5. 回溯是王子和渡魂人之间的私人契约【定】
- 永昼不是契约的条件，终结永昼不会让回溯停止、王子消散，也不会自动进入真结局。
- canon 现有的规则继续有效：
  - 锚点固定
  - 失败或收潮时召回
  - 只有王子记得
  - 实物和盟友要每轮重新取得
  - 真结局是自愿解约
- canon 写的"秘印和回溯共享中断渡海的原理、亲历一次终止永昼后才学会解约"，在新规则下改为【议】：
  - 王子在秘印前**亲眼看到**灵魂被释放后，才第一次理解"束缚可以被放下"。
  - 这是认知上的契机，不是机制上的依赖。
  - 解约的权利一直在王子手里，只是他不知道。
  - 这样保留了分阶段开放，又不把契约挂在秘印上。

## 6. 宗教与纹章：重新审视【定：起源与旧纹章方向；纹章图样待画】
设计顺序按用户交接稿第 6 节。Claude 的初步想法（全部【议】）：
1. **宗教早于永昼**：太阳教会原本是渔民和水手的信仰，敬拜给航海带来方向的太阳。大寒冬时教会造出永昼之日，信仰从"敬天"变成了"守约"。
   - 有了这条，终止永昼不必消灭宗教。教会里可以出现一支改革派，想回到旧信仰，例如静息院的见习修士（canon 已有这个配角）。
2. **王室早于永昼**：王朝起于海上建国。原始纹章是**海与星**：一颗指引航向的北星，加海浪。永昼建立后，王室把纹章改成了白底金八芒日，以示和教会立约。
   - 视觉上：旧王庭的遗迹和沉王群像上刻的是星与浪，王都刻的是太阳。
   - 王子的私人纹章是王冠，可以改成"星冠"，回到王朝的本源。终止永昼的结局里，星纹重新出现。
3. 教会圣徽、王室纹章、永昼设施标志三者分开设计，共享太阳母题，但永昼设施的标志不能透露真相。
4. 现有美术（白金日纹、红斜带）先保留不废弃。纹章重画等世界观定稿后再说。

## 8. 结局的修订（结构不变）
- "终止永昼"在三次决定里的含义明确为：**停止强制消耗灵魂**。秘印释放尚存的囚魂，永昼之日熄灭，全国的圣火龛在这个冬天之后不再被点燃。
  - 代价是全国性的，取代原来"只影响王都"的写法。
  - 应对办法沿用 canon：粮储、替代港口、普通燃料、过冬政策。
- 不增加第三个选项。只关光、不关火的做法不成立，理由见第 2 节。
- E05–E08 的尾声改为写全国：城镇第一次在冬天烧木头和泥炭，外岛和王都终于一样冷，也一样黑。
